# Finding codes: layout and render

> Offline copy. Read the official docs for your version at https://olejbondahl.github.io/fransys/X.Y.Z/ (X.Y.Z is `fransys.__version__`), or https://olejbondahl.github.io/fransys/X.Y.Z/llms.txt. Use this copy only offline.

Codes the layout and the drawing stage emit. Who acts is explained in [`findings.md`](findings.md).

| Code | Severity | Stage | Who acts | Meaning | Fix |
| --- | --- | --- | --- | --- | --- |
| ALIGN_DROPPED | WARNING | render | consumer | Symbols of a row group or a band rank, mated pins, or the legs of a trunk, cannot stand level because the stacks in their columns contradict it; layout dropped the alignment. | Shorten the stack, or move the members to the same end of their columns. Write: d.layout.chain(a, b) to stand them in one column, source first. |
| ANNEX_UNPLACED | WARNING | render | consumer | A tag, marking or table beside a symbol found no spot free of every outline, wire and text; it stands at its first spot, over what blocks it. | No call clears this: shorten the tag of <subject>, or move the symbols around it to leave a corner free. |
| BLOCK_NOT_PLACED | ERROR | render | Fransys | A block stands in no row of any page, or a whole block in more than one, so layout draws it by no rule; the message names the block and the stage. | No call clears this: send the smallest model that shows it. |
| BOARD_NETS_NOT_DRAWN | WARNING | render | consumer | A board shares its unit with another top-level device, so layout draws it as a black box and drops the nets between its parts. | Make the board its own unit's only top-level device, with its parts as children. Write: @fr.unit(...) def board(d): b = d.device("A1", "DEMO-PCB-IO") and d.device("J1", "DEMO-CONN-2P", parent=b) in a unit of their own. |
| CARD_OVERFULL | WARNING | render | consumer | A box has more attached columns than its card holds; the columns that do not fit stand free of the card. | No call clears this: wire fewer columns to <subject>, or split the box into two devices. |
| CHAIN_REFUSED | WARNING | render | consumer | Boxes wired box to box do not make a chain that draws as one column: a ring, a box joined to three boxes, a box also wired by a trunk, or pins that do not face; or a box in parallel below another box, which has no layout yet. The message names the boxes and the hop that failed; the boxes are drawn unchained. | Wire each box only to the next, with the pins toward the previous box on the north side and those toward the next on the south side. Write: d.series(a, b, c). A box in parallel below another box has no layout yet; it is drawn unchained. |
| CONNECTION_DRAWN_TWICE | WARNING | render | Fransys | Two routes on one page join the same ports: the wires of a page close a loop. | No call clears this: send the smallest model that shows it. The message names the page. |
| CONNECTION_NOT_DRAWN | WARNING | render | consumer | The drawn ports of one physical net do not lie in one drawn piece: a port no wire, dot, link or reference reaches, or two pieces with no reference pair between them. A net with a port off the document needs each drawn port reached by a wire or a stub. Not NET_CUT_BY_SET, which names a net drawn in several sets. | Give both ends a location so layout can route or cut them; check `layout.route`, `layout.symbol_placement` and `layout.page`. Write: d.layout.draw_in(f, g) for the open end's function. |
| CONNECTION_TO_UNDRAWN | WARNING | render | consumer | A connection, net group or rail has an end whose function layout never draws. | Put the missing end's item in a drawn unit or location, or remove the connection. Write: d.layout.draw_in(f, g) for that item. |
| DIAGRAM_BOX_OVERLAP | ERROR | render | Fransys | Two boxes of a block diagram or of an overview view, or a tab and a box, overlap. | No call clears this: send the smallest model that shows it. |
| DIAGRAM_CABLE_FANOUT | INFO | render | note | A cable reaches three or more boxes, so the block diagram draws a line from its first box to each other. | Nothing is wrong; split the cable only if a line per pair is not wanted. |
| DIAGRAM_CABLE_ONE_BOX | INFO | render | note | A cable's ends reach one box or none, so the block diagram draws no line for it. | Usually nothing to fix: the cable runs inside one box, or an end is an unmated plug. |
| DIAGRAM_COLUMN_TOO_TALL | INFO | render | note | A block diagram gets no page because its tallest column holds more boxes than one sheet holds; the message gives the column, its boxes and how many fit. | A known limit of the system diagram: no setting changes it. `DOCUMENT_NO_DRAWINGS` is the error that stops the write. |
| DIAGRAM_LABEL_STRUCK | INFO | render | Fransys | A line of a block diagram or an overview view passes through a line label. | Fransys could not draw this cleanly; please report it with the smallest model |
| DIAGRAM_LINES_SHARE_TRACK | INFO | render | Fransys | Two cables of a block diagram or an overview view run along one track. | Fransys could not draw this cleanly; please report it with the smallest model |
| DIAGRAM_LINE_OFF_BOX | ERROR | render | Fransys | A line of a block diagram or an overview view does not end on its box's outline or tab. | No call clears this: send the smallest model that shows it. |
| DIAGRAM_LINE_THROUGH_BOX | ERROR | render | Fransys | A line of a block diagram or an overview view crosses a box other than its own two. | No call clears this: send the smallest model that shows it. |
| DIAGRAM_LOOSE_WIRE | INFO | render | note | In the system reading, a wire with no cable joins two boxes and is not drawn. | Usually nothing to fix: the unit pages show it as stubs. Put it in a cable to give it a line. |
| DIAGRAM_TEXT_OVERLAP | ERROR | render | Fransys | Two texts of a block diagram or an overview view overlap. | No call clears this: send the smallest model that shows it. |
| DRAWING_SHORTS_NETS | ERROR | render | Fransys | The wires, junction dots and references of the drawings join ports of two physical nets, or a wire ends on another net's wire with no junction dot. | No call clears this: send the smallest model that shows it. The message names the page. |
| DRAW_PROBLEM | ERROR | render | Fransys | A drawing set holds a record the renderer cannot draw, such as an unknown symbol key or an outline that is not a rectangle; the set draws no page. | No call clears this: send the smallest model that shows it. The message names the record and what the renderer expected. |
| FILL_UNDER_MIN | WARNING | render | consumer | A page is filled less than the minimum because no cut of the blocks fills it more. | Merge the group with its neighbour, or drop its page break, so the page fills. Write: d.layout.keep_together(a, b) for the neighbouring groups. |
| FUNCTION_NOT_DRAWN | WARNING | render | consumer | A function of a connected set has no symbol (reason function_without_symbol), so the layout leaves it out of the drawing. The message names the function and the reason. | Give the function a part whose kind has a symbol. Write: d.device("K1", "DEMO-RLY-2CO-24") |
| FUNCTION_NOT_WIRED | WARNING | render | consumer | A function's symbol is on no net, so the page leaves it off (reason function_unwired). The message names the function. | Wire a pin of <subject> to another function, or remove it. Write: d.detail.wire(a, b). |
| HEAD_OFF_LEGS | WARNING | render | consumer | A trunk is cut by a page and its head stands on the page with fewer of its legs. | Reorder the groups so the head and most of its legs share a page. Write: d.layout.order(a, b) with the head's group first. |
| HINT_NOT_READ | WARNING | render | consumer | An authored layout hint is kept in the model but the core path does not read it, so the drawing ignores it. The message names the hint and the function. | No call clears this: delete the d.layout.side line for <subject> from the design, or keep it for the old engine, which reads it. |
| KEEP_TOGETHER_UNMET | WARNING | render | consumer | An authored `keep_together` set could not be kept on one page (it does not fit, its groups sit on different drawing sets, or `break_before` is invalid). | Shrink the set, move its groups onto one drawing set, or drop the hint. Write: d.layout.keep_together(a, b) only for groups on one drawing set. |
| LANE_WIRE_DROPPED | WARNING | render | consumer | Two consecutive cells of a lane have no pin facing each other, or a facing pin on no net, so no wire is drawn between them; the message names the cells. | Put the facing pins of <subject> and its neighbour on one net. Write: d.detail.wire(pin_a, pin_b). |
| LAYOUT_MISSING | ERROR | render | consumer | The model has connected functions to draw, but layout made no page for them. A function with nothing connected is drawn on no page and does not count. | Wire the functions you want drawn into current paths inside function blocks. Write: d.series(a, b, c) |
| MARKER_UNPAIRED | WARNING | render | Fransys | A reference marker is drawn and the marker it refers to is drawn on no page. | No call clears this: send the smallest model that shows it. The message names the page. |
| MARKER_UNPLACED | WARNING | render | Fransys | A reference marker has no place inside the page: every level of its stagger leaves the content box, so layout draws no marker there; the message names its pin and page. | No call clears this: send the smallest model that shows it. |
| MISSING_JUNCTION_DOT | WARNING | render | Fransys | A wire ends on the middle of another wire of the same net with no junction dot, so the page does not show them joined. | No call clears this: send the smallest model that shows it. The message names the page. |
| NET_CUT_BY_SET | WARNING | render | consumer | A net has one end in a drawing set and its other end in another (a different unit or location), so the core path draws it in neither. The message names the net and the set. | Put the functions the net joins in one unit and one location. Write: d.device("K1", "DEMO-RLY-2CO-24", place="R") for each, with the same place. |
| NET_NOT_DRAWN | WARNING | render | consumer | A net of two or more ends has under two drawn pins, so it is left out. A lone pin gives none. The message names the port. | Give the net a second drawn pin. Write: d.series(a, <subject>) |
| NOT_SERIES_PARALLEL | WARNING | render | consumer | The named symbols are wired as a bridge, which no series or parallel holds. | Wire them as series and parallel parts. Write: d.series(a, d.parallel(b, c), d) |
| NO_BLOCK | WARNING | render | consumer | A box is drawn but belongs to no block, or to more than one, so layout places it by no rule; the message names it. | Wire <subject> to one function block, or remove it. Write: d.layout.draw_in(<subject>, g) to draw it in a group. |
| NO_CELL | WARNING | render | consumer | A symbol is drawn but stands in no cell of any column, or in more cells than it has elements, so layout places it by no rule; the message names it. | Wire <subject> into a current path, or remove it. Write: d.layout.chain(a, <subject>) to stand it in a column, source first. |
| ORDER_HINT_UNMET | WARNING | render | consumer | An authored order hint names two groups that are not on the same drawing set, so no page order can honour it. | Move both groups onto one drawing set, or drop the hint. Write: d.layout.order(a, b) for groups on one drawing set. |
| OUT_OF_PAGE | WARNING | render | consumer | A symbol body or a text lies outside the content box of its page. | Split the block that holds it, or use a taller sheet. Write: [paper] default = "A2". |
| OVERLAP | WARNING | render | consumer | Two drawn boxes (symbol bodies, and symbols drawn at a pin end such as a power symbol), a text and a body, two texts, or a wire and a text meet on one page; the message names the first of them. | No call clears this: send the smallest model that shows it. The message names the page and the members. |
| OVERVIEW_UNPLACED | ERROR | render | Fransys | The overview placer found no room plan for one view of the system overview, so the page would have no positions for it. | No call clears this: send the smallest model that shows it. |
| PAGE_OVERFLOW | ERROR | render | consumer | A row of one block is taller than the page, so it stands on a page of its own. | Split <block> into smaller function blocks, or use a taller sheet. Write: [paper] default = "A2" in the settings file, passed as fr.build(settings=fr.settings(path)) |
| PLACEMENT_PROBLEM | ERROR | render | Fransys | The placement core cannot take the design, or a set of it; the set draws no page. The message names the thing and what the core expected. | No call clears this: send the smallest model that shows it. |
| REFERENCE_OFF_DOCUMENT | WARNING | render | consumer | A printed reference points to a page that no page of its own document holds, and its text prints no location, so a reader cannot tell which document to open. The message names the reference, its page and the target page. | Print both drawing sets in one document, or give the target's drawing set a location so the reference names it. Write: fr.document(<preset>, <subject>, cover=<cover>) |
| ROUTE_FAILED | ERROR | render | consumer | No orthogonal path on the wiring grid could be found between the two ports of a connection. | Usual causes: a redundant conductor between two points already on one net (rewire to a point already routed), or crowded geometry around the ports. Write: d.detail.wire(a, b) between points already on one net. |
| ROUTE_WRONG_PORT | ERROR | render | Fransys | A wire of one lane ends on a port of one net and on a port of another net. | No call clears this: send the smallest model that shows it. The message names the page. |
| SET_WITHOUT_PAGE | WARNING | render | consumer | A drawing set holds symbols but every net of them has its other end in another set, so the core path gives it no page. The message names the set. | Put the set's functions in the unit and location of the functions they are wired to. Write: d.device("K1", "DEMO-RLY-2CO-24", place="R") with the same place. |
| SHEET_FORMAT_UNUSED | WARNING | render | consumer | An authored sheet format is named by no layout profile, so pages use the house sheet (or the profile's format). | Name it in the settings file's [paper] table, or remove it. Write: [paper] default = "A2" in the settings file, passed as fr.build(settings=fr.settings(path)). |
| SPARE_FUNCTIONS | INFO | render | note | A function on no net, on an item that has other wired functions, is a spare: it is left off the schematic. One finding per document names the count and the items. | Nothing is wrong; wire the function if it is not a spare. |
| SPARE_TERMINALS | INFO | render | note | A terminal none of whose nets has a second end is a spare: it stands in the terminal list and is not drawn on the schematic. One finding per document names the count and the strips. | Nothing is wrong; wire the terminal if it is not a spare. |
| SYMBOL_PORT_MISSING | ERROR | render | consumer | A model port matches no port on its drawn symbol by any of the three binding rules. | Fix the part's port names, or map them with port_map or a symbol choice. Write: d.layout.symbol(<target>, <symbol>, port_map=<mapping>) |
| TEXT_OVERLAP | INFO | render | Fransys | Two texts on a page overlap, or a text overlaps a symbol body it does not belong to. | Fransys could not draw this cleanly; please report it with the smallest model |
| TEXT_TOO_SMALL | WARNING | render | consumer | A layout profile's `text_height_mm` is under its `min_text_height_mm`. Once per profile; nothing is shrunk or grown. | Raise `text_height_mm`, or lower `min_text_height_mm` if the small text is intended. Write: d.layout.profile(text_height_mm=...). |
| TITLE_BLOCK_NOTICE_OVERFLOW | WARNING | render | consumer | The `notice` text passed to `fr.document(notice=)` does not fit the notice cell and would be cut. | Shorten the notice of <subject> to fit its cell. Write: fr.document(<preset>, <subject>, cover=<cover>, notice=<shorter notice>) |
| TITLE_BLOCK_NO_ROOM | WARNING | render | consumer | The sheet format's title-block band is under the required 20mm, or its title block is under the required 97.5mm wide. | Use a sheet format with a taller title-block band or a wider title block. Write: [paper] default = "A2" in the settings file, passed as fr.build(settings=fr.settings(path)) |
| TITLE_BLOCK_STACK_OVERLAP | ERROR | render | consumer | The profile's text height needs a taller title-block band than the sheet format has, so a title-block label overlaps its value. | Use a sheet format whose title-block band is at least the named height, or the house text height. Write: [paper] default = "A2" in the settings file, passed as fr.build(settings=fr.settings(path)) |
| TITLE_BLOCK_TEXT_OVERFLOW | WARNING | render | consumer | A one-line title-block field (title, number, customer, revision, date, author, page title, scope or sheet counter) does not fit its cell. | Shorten the field the message names. Write: d.project(title=<shorter text>, number=<number>, customer=<shorter text>, revision=<n>, author=<shorter text>) for the title, number, customer, revision or author, or d.layout.page_title(<thing>, <shorter text>) for a page title. |
| UNKNOWN_SYMBOL_KEY | ERROR | el | consumer | A function's chosen symbol key is not in the installed symbol library; it is drawn as a generic box. | Fix the symbol key of <subject> in its rule, choice or part data, or install a library version that has it. Write: d.layout.symbol(<target>, <symbol>) |
| UNPRINTED_SET | WARNING | render | consumer | A drawing set has pages but no document prints it, so its items are not in any export. The message names the set and its items. | Add a document for the set's unit or location, or nest the unit in one that has one. Write: fr.document(fr.DocumentPreset.CABINET_SCHEMATIC, "demo-mini-mcc") |
| WIDER_THAN_PAGE | WARNING | render | consumer | A row of columns is wider than the page even at its closest spacing. | Shorten the row, lower the column count of the block, or raise the page width. Write: [paper] default = "A2" in the settings file, passed as fr.build(settings=fr.settings(path)). |
| WIRE_MEETS_NET | WARNING | render | consumer | A fixed wire (a lane wire, join, trunk or drop) meets another net's wire and no detour exists, so it is drawn as placed; the message names the wire and its ends. | Move a symbol of <subject> or widen the gap beside it so the wire has a free path. Write: d.layout.chain(a, b) to stand the two symbols in one column. |
| WIRE_NOT_ORTHOGONAL | WARNING | render | Fransys | A drawn wire has a segment that is neither horizontal nor vertical. | No call clears this: send the smallest model that shows it. The message names the page. |
