# Finding codes: layout and render

> Offline copy. Read the official docs for your version at https://olejbondahl.github.io/fransys/X.Y.Z/ (X.Y.Z is `fransys.__version__`), or https://olejbondahl.github.io/fransys/X.Y.Z/llms.txt. Use this copy only offline.

Codes the layout and the drawing stage emit. Who acts is explained in [`findings.md`](findings.md).

| Code | Severity | Stage | Who acts | Meaning | Fix |
| --- | --- | --- | --- | --- | --- |
| CHAIN_BROKEN | WARNING | render | consumer | A connection between two "pole" cells was severed into a marker pair though its net has only those ports. | Keep the whole circuit in one function block, so no page break falls inside it ([Drawing well](drawing.md)). |
| CONNECTION_DRAWN_TWICE | ERROR | render | consumer | A connection (or net-group edge) is drawn by more than one route, or also contradicted by a cut decision. | Remove the duplicate so the connection is drawn or cut once. |
| CONNECTION_NOT_DRAWN | ERROR | render | consumer | A conductor or net-group edge is neither routed on a shared page nor cut with a marker. | Give both ends a location so layout can route or cut them; check `layout.route`, `layout.symbol_placement` and `layout.page`. |
| CONNECTION_TO_UNDRAWN | WARNING | render | consumer | A connection, net group or rail has an end whose function layout never draws. | Put the missing end's item in a drawn unit or location, or remove the connection. |
| DIAGRAM_BOX_OVERLAP | ERROR | render | Fransys | Two boxes of a block diagram or of an overview view, or a tab and a box, overlap. | A Fransys defect: send the smallest model that shows it. |
| DIAGRAM_CABLE_FANOUT | INFO | render | note | A cable reaches three or more boxes, so the block diagram draws a line from its first box to each other. | Nothing is wrong; split the cable only if a line per pair is not wanted. |
| DIAGRAM_CABLE_ONE_BOX | INFO | render | note | A cable's ends reach one box or none, so the block diagram draws no line for it. | Usually nothing to fix: the cable runs inside one box, or an end is an unmated plug. |
| DIAGRAM_COLUMN_TOO_TALL | INFO | render | note | A block diagram gets no page because its tallest column holds more boxes than one sheet holds; the message gives the column, its boxes and how many fit. | A known limit of the system diagram: no setting changes it. `DOCUMENT_NO_DRAWINGS` is the error that stops the write. |
| DIAGRAM_LABEL_STRUCK | INFO | render | Fransys | A line of a block diagram or an overview view passes through a line label. | Fransys could not draw this cleanly; please report it with the smallest model |
| DIAGRAM_LINES_SHARE_TRACK | INFO | render | Fransys | Two cables of a block diagram or an overview view run along one track. | Fransys could not draw this cleanly; please report it with the smallest model |
| DIAGRAM_LINE_OFF_BOX | ERROR | render | Fransys | A line of a block diagram or an overview view does not end on its box's outline or tab. | A Fransys defect: send the smallest model that shows it. |
| DIAGRAM_LINE_THROUGH_BOX | ERROR | render | Fransys | A line of a block diagram or an overview view crosses a box other than its own two. | A Fransys defect: send the smallest model that shows it. |
| DIAGRAM_LOOSE_WIRE | INFO | render | note | In the system reading, a wire with no cable joins two boxes and is not drawn. | Usually nothing to fix: the unit pages show it as stubs. Put it in a cable to give it a line. |
| DIAGRAM_TEXT_OVERLAP | ERROR | render | Fransys | Two texts of a block diagram or an overview view overlap. | A Fransys defect: send the smallest model that shows it. |
| DRAWING_SHORTS_NETS | INFO | render | Fransys | A page draws two nets joined that the wiring keeps apart: a stub, a wire end or a power symbol lies on, or crosses, another net's wire or symbol. | A Fransys defect: send the smallest model that shows it. Check first that no authored hint crowds the nets. |
| FUNCTION_UNPLACED_IN_COLUMN | INFO | render | consumer | A function is on no current path, authored or found from the wiring, so layout placed it alone in its own column. | Wire the function into a current path (`d.series`, or `d.detail.wire` with two poles per net), or name the path with `d.layout.chain`; see drawing.md. |
| GROUP_SPLIT | WARNING | render | consumer | A group of columns is wider than one page, so layout split it between columns. | Split the block into function blocks that each fit one page ([Drawing well](drawing.md)). |
| JOIN_UNALIGNED | INFO | render | Fransys | Same-net, same-facing ports at one end of neighbouring columns could not be aligned onto one row, so layout drew references. | Fransys could not draw this cleanly; please report it with the smallest model |
| KEEP_TOGETHER_UNMET | WARNING | render | consumer | An authored `keep_together` set could not be kept on one page (it does not fit, its groups sit on different drawing sets, or `break_before` is invalid). | Shrink the set, move its groups onto one drawing set, or drop the hint. |
| LABEL_UNPLACED | WARNING | render | consumer | A tag, marking or cross-reference found no free spot and sits at its default. | Use the house `text_height_mm` 1.8; give the design structure ([Drawing well](drawing.md)). If it still fires, a Fransys defect: send the smallest model that shows it. |
| LAYOUT_MISSING | ERROR | render | consumer | The model has connected functions to draw, but layout made no page for them. A function with nothing connected is drawn on no page and does not count. | Add a document so layout runs, and check the drawn location or unit holds the connected content. |
| LIBRARY_VERSION_MISMATCH | WARNING | render | consumer | A placement was laid out against a symbol library version other than the installed one. | Re-run layout (build) with the installed `electrical_symbols` version. |
| LINE_ON_OUTLINE | INFO | render | Fransys | A harness line runs along a unit outline's edge, so the two read as one stroke. | Fransys could not draw this cleanly; please report it with the smallest model |
| LINK_FANOUT | WARNING | render | consumer | More than one severed link crosses between the same two pages on one net. | Join the net once with a terminal instead of severing it repeatedly between the same two pages. |
| LINK_PARTNER_UNLOCATED | WARNING | render | consumer | A signal crosses into a drawing set with no authored location, so its marker has no located prefix. | Name the drawing set's unit or location. |
| LONE_CELL | WARNING | render | consumer | A symbol has nothing connected, so it is drawn on no page; the message names the pins to wire and no page. Or a symbol stands alone on a page though its column has cells elsewhere. | Wire the named pins, or remove the device if it is not used; or move the column's cells onto one page. A unit's own open boundary functions and the item box standing under them, spare contacts and spare terminals never give it (decisions layout-0077, layout-0202 and layout-0218). |
| MARKER_UNPAIRED | ERROR | render | Fransys | A severed connection's owner or user marker is missing, or a page marker matches no severed decision. | A Fransys defect: send the smallest model that shows it. Check first that the cut decision and its markers agree. |
| ORDER_HINT_UNDONE | WARNING | render | consumer | An authored `keep_together` set pulled a group across an authored `order` hint, so the page order is not the one the `order` hint asked for. | Drop the `keep_together` hint or the `order` hint, or order both hints to agree; `keep_together` wins when you keep both. |
| ORDER_HINT_UNMET | WARNING | render | consumer | An authored order hint names two groups that are not on the same drawing set, so no page order can honour it. | Move both groups onto one drawing set, or drop the hint. |
| OUT_OF_CONTENT_BOX | WARNING | render | consumer | A symbol's keep-out box, label, marker box or route vertex sits outside the page's content box; the message ends " at p<page>:<cell>", with the drawing set before the page (`p<set>.<page>`) only when the layout has more than one. | Declare the supplies, wire each circuit as a current path, or split it into function blocks ([Drawing well](drawing.md)). If it still fires, a Fransys defect: send the smallest model that shows it. |
| OVERVIEW_UNPLACED | ERROR | render | Fransys | The overview placer found no room plan for one view of the system overview, so the page would have no positions for it. | A Fransys defect: send the smallest model that shows it. |
| PAGE_OVERFULL | WARNING | render | consumer | A page's rows are taller than the content box; nothing is scaled. | Declare the supply, or split the circuit into function blocks ([Drawing well](drawing.md)). If it still fires, a Fransys defect: send the smallest model that shows it. |
| PAGE_UNDERFILLED | INFO | render | note | A schematic page whose drawn content covers under half of the content box; its message gives the share and the page reference (`+C<set>p<page>` or `(p<set>.<page>)`, from the naming pass). Nothing is moved or scaled. | No action is needed. The page is mostly empty; a larger `module_mm` spreads the content ([Drawing well](drawing.md)). |
| PIN_MAP_INCOMPLETE | ERROR | render | consumer | A symbol node has no model port bound to any of its symbol ports at all. | Add the missing model port or a `port_map`/symbol choice. |
| POWER_SYMBOL_UNPLACED | INFO | render | Fransys | No lead of up to 12 grids kept a power symbol clear of its neighbours, so it keeps one grid and may touch. | Fransys could not draw this cleanly; please report it with the smallest model |
| REDUNDANT_JOG | INFO | render | Fransys | A drawn route leaves a straight line and returns to it where a straight run was free. | Fransys could not draw this cleanly; please report it with the smallest model |
| REFERENCE_BOX_EXCEEDS_ROOM | WARNING | render | consumer | A drawing set has 100 or more cross-reference numbers (#n) or pages; a reference box then exceeds layout's room. | Keep each drawing set under 100 pages and 100 `#n` numbers: split the design into units. |
| REFERENCE_OFF_DOCUMENT | WARNING | render | consumer | A printed reference points to a page that no page of its own document holds, and its text prints no location, so a reader cannot tell which document to open. The message names the reference, its page and the target page. | Print both drawing sets in one document, or give the target's drawing set a location so the reference names it. |
| ROUTE_FAILED | ERROR | render | consumer | No orthogonal path on the wiring grid could be found between the two ports of a connection. | Usual causes: a redundant conductor between two points already on one net (rewire to a point already routed), or crowded geometry around the ports. |
| ROUTE_NEAR_FLAG_STUB | INFO | render | note | No path kept a wire off every link marker's stub, rail and branch (layout-0243), so it was drawn in the old room, which ignores that ink. It may touch another net's marker. The message names the page and the wire. | Send the smallest model that shows it: Fransys could not draw this cleanly. |
| ROUTE_SHORTS_NETS | ERROR | render | Fransys | A drawn route touches a port of another physical net, or two routes of different physical nets touch on the page. | A Fransys defect: send the smallest model that shows it. Check first that no authored hint crowds the nets. |
| ROUTE_WRONG_PORT | ERROR | render | Fransys | A route does not run between the two ports it claims to join. | A Fransys defect: send the smallest model that shows it. |
| SHEET_FORMAT_UNUSED | WARNING | render | consumer | An authored sheet format is named by no layout profile, so pages use the house sheet (or the profile's format). | Name it in the layout profile, or remove it. |
| STUBS_NOT_STACKED | INFO | render | note | Leaving-line stubs of one page whose texts meet found no free staircase (layout-0256): the room, a shape or another line was in the way. They stay as drawn and their texts overlap. The message names the page. | Move a unit or cable so the lines leave apart, or send the smallest model showing it. |
| SYMBOL_DEFAULTED | INFO | render | note | A function matched no symbol rule or choice, so it was drawn as a plain labelled box. | Add a symbol rule or choice for the function's kind or category if a real symbol is wanted. |
| SYMBOL_OVERLAP | INFO | render | Fransys | The keep-out boxes of two symbols on one page overlap. | Fransys could not draw this cleanly; please report it with the smallest model |
| SYMBOL_PORT_MISSING | ERROR | render | consumer | A model port matches no port on its drawn symbol by any of the three binding rules. | Fix the part's port names, or add a `port_map`/symbol choice. |
| TEXT_CROSSED_BY_ROUTE | INFO | render | Fransys | A link marker's stub runs through a text box (a label or another marker's box). | Fransys could not draw this cleanly; please report it with the smallest model |
| TEXT_OVERLAP | INFO | render | Fransys | Two texts on a page overlap, or a text overlaps a symbol body it does not belong to. | Fransys could not draw this cleanly; please report it with the smallest model |
| TEXT_TOO_SMALL | WARNING | render | consumer | A layout profile's `text_height_mm` is under its `min_text_height_mm`. Once per profile; nothing is shrunk or grown. | Raise `text_height_mm`, or lower `min_text_height_mm` if the small text is intended ([Drawing well](drawing.md)). |
| UNIT_GROUP_SPLIT | WARNING | render | consumer | A unit group is wider than one page, so layout split it; each page keeps an outline for its own interfaces. | Even the edges with side hints (`d.layout.side`), or give the unit fewer harness interfaces. |
| UNKNOWN_SYMBOL_KEY | ERROR | render | consumer | A placement's symbol key is not in the installed symbol library. | Fix the symbol key (rule, choice, or part data), or install a library version with it. |
| WIRE_NOT_ORTHOGONAL | INFO | render | Fransys | A drawn route has a non-orthogonal segment (not purely horizontal or vertical). | Fransys could not draw this cleanly; please report it with the smallest model |
| WIRE_OVER_LABEL | INFO | render | Fransys | A drawn route runs through a label's (or link marker's) box. | Fransys could not draw this cleanly; please report it with the smallest model |
| WIRE_THROUGH_SYMBOL | INFO | render | Fransys | A drawn route runs through the keep-out box of a symbol it does not end at. | Fransys could not draw this cleanly; please report it with the smallest model |
