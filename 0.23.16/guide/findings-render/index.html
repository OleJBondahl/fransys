Finding codes: layout and render

Codes the layout and the drawing stage emit. Who acts is explained in findings.md.

A drawing set whose layout failed and drew nothing complete (PLACEMENT_PROBLEM, or an ERROR that stops its drawing) is not checked; every complete set is, and fr.write still refuses.

Code Severity Stage Who acts Meaning Fix
ALIGN_DROPPED WARNING render consumer Symbols of a row group or a band rank, mated pins, or the legs of a trunk, cannot stand level because the stacks in their columns contradict it; layout dropped the alignment. Shorten the stack, or move the members to the same end of their columns. Write: d.series(a, b, c) to stand a path in one column.
ANNEX_UNPLACED WARNING render consumer A tag, marking or table beside a symbol found no spot free of every outline, wire and text; it stands at its first spot, over what blocks it. No call clears this: shorten the tag of , or move the symbols around it to leave a corner free.
BLOCK_NOT_PLACED ERROR render Fransys A block stands in no row of any page, or a whole block in more than one, so layout draws it by no rule; the message names the block and the stage. No call clears this: send the smallest model that shows it.
BOARD_NETS_NOT_DRAWN ERROR render consumer A board shares its unit with another top-level device, so layout draws it as a black box and drops the nets between its parts. Make the board its own unit's only top-level device, with its parts as children. Write: @fr.unit(...) def board(d): b = d.device("A1", "DEMO-PCB-IO") and d.device("J1", "DEMO-CONN-2P", parent=b) in a unit of their own.
CARD_OVERFULL INFO render note The card of a box is wider than a page; the columns that do not fit stand free of the card on later pages. Nothing is wrong; each such column is joined to its pin of by a drawn tag pair.
CHAIN_REFUSED INFO render note Boxes wired box to box do not make a chain that draws as one column: a ring, a box joined to three boxes, a box also wired by a trunk, or pins that do not face; or a box in parallel below another box, which has no layout yet. The message names the boxes and the hop that failed; the boxes are drawn unchained. Nothing is wrong; the boxes are drawn unchained (rule CHAIN-COLUMN).
CONNECTION_DRAWN_TWICE ERROR render Fransys Two routes on one page join the same ports: the wires of a page close a loop. No call clears this: send the smallest model that shows it. The message names the page.
CONNECTION_NOT_DRAWN ERROR render consumer The drawn ports of one physical net do not lie in one drawn piece: a port no wire, dot, link or reference reaches, or two pieces with no reference pair between them. A group the model joins with a port off the document needs each drawn piece to end in a stub that names a port of the group outside it. Give both ends a location so layout can route or cut them; check layout.route, layout.symbol_placement and layout.page. Wire the open end's function into a function block, or move its device into a unit. Write: d.series(a, b, ...) to draw it in its block.
CONNECTION_TO_UNDRAWN WARNING render consumer A connection, net group or rail has an end whose function layout never draws. Put the missing end's item in a drawn unit or location, or remove the connection. Write: d.function(name, text) to place that item in a drawn group.
DANGLING_WIRE_END ERROR render Fransys A Fransys drawing defect: a drawn wire ends where no symbol port, junction dot, reference marker, other wire or joined bundle lane end stands. No call clears this: send the smallest model that shows it. The message names the page.
DIAGRAM_BOX_OVERLAP ERROR render Fransys Two boxes of a block diagram or of an overview view, or a tab and a box, overlap. No call clears this: send the smallest model that shows it.
DIAGRAM_CABLE_FANOUT INFO render note A cable reaches three or more boxes, so the block diagram draws a line from its first box to each other. Nothing is wrong; split the cable only if a line per pair is not wanted.
DIAGRAM_CABLE_ONE_BOX INFO render note A cable's ends reach one box or none, so the block diagram draws no line for it. Usually nothing to fix: the cable runs inside one box, or an end is an unmated plug.
DIAGRAM_LABEL_STRUCK INFO render Fransys A line of a block diagram or an overview view passes through a line label. Fransys could not draw this cleanly; please report it with the smallest model
DIAGRAM_LINES_SHARE_TRACK INFO render Fransys Two cables of a block diagram or an overview view run along one track. Fransys could not draw this cleanly; please report it with the smallest model
DIAGRAM_LINE_OFF_BOX ERROR render Fransys A line of a block diagram or an overview view does not end on its box's outline or tab. No call clears this: send the smallest model that shows it.
DIAGRAM_LINE_THROUGH_BOX ERROR render Fransys A line of a block diagram or an overview view crosses a box other than its own two. No call clears this: send the smallest model that shows it.
DIAGRAM_LOOSE_WIRE INFO render note In the system reading, a wire with no cable joins two boxes and is not drawn. Usually nothing to fix: the unit pages show it as stubs. Put it in a cable to give it a line.
DIAGRAM_TEXT_OVERLAP ERROR render Fransys Two texts of a block diagram or an overview view overlap. No call clears this: send the smallest model that shows it.
DOT_ON_CROSSING ERROR render Fransys A junction dot stands where two wires cross through each other, so the page shows them joined when they are not. No call clears this: send the smallest model that shows it. The message names the page.
DRAWING_SHORTS_NETS ERROR render Fransys The wires, junction dots and references of the drawings join ports of two physical nets, or a wire ends on another net's wire with no junction dot. No call clears this: send the smallest model that shows it. The message names the page.
DRAW_PROBLEM ERROR render Fransys A drawing set holds a record the renderer cannot draw, such as an unknown symbol key or an outline that is not a rectangle; the set draws no page. No call clears this: send the smallest model that shows it. The message names the record and what the renderer expected.
FILL_UNDER_MIN WARNING render consumer A page is filled less than the minimum because no cut of the blocks fills it more. Merge the group with its neighbour so the page fills. Write: d.function(name, text) to draw a device in the neighbour group.
FUNCTION_NOT_DRAWN ERROR render consumer A function of a connected set has no symbol (reason function_without_symbol), so the layout leaves it out of the drawing. The message names the function and the reason. Give the function a part whose kind has a symbol. Write: d.device("K1", "DEMO-RLY-2CO-24")
FUNCTION_NOT_WIRED WARNING render consumer An undeclared function's symbol is on no net, so the page leaves it off (reason function_unwired). The message names the function. Wire a pin of to another function, declare it spare, or remove it. Write: d.device("K1", "DEMO-RLY-2CO-24", unused=True)
HARNESS_WIRE_MISMATCH ERROR render Fransys A wire drawn in a cable or harness block page differs from the harness-wire row of the model: another core, other ends or another cable, or a row is not drawn once. The message names the cable, the core and the ends. No call clears this: send the smallest model that shows it. The message names the cable and the core.
HEAD_OFF_LEGS WARNING render consumer A trunk is cut by a page and its head stands on the page with fewer of its legs. Reorder the groups so the head and most of its legs share a page. Write: d.layout.order(a, b) with the head's group first.
LANE_WIRE_DROPPED ERROR render consumer Two consecutive cells of a lane have no pin facing each other, or a facing pin on no net, so no wire is drawn between them; the message names the cells. Put the facing pins of and its neighbour on one net. Write: d.series(pin_a, pin_b).
MARKER_UNPLACED WARNING render Fransys A reference marker has no place inside the page: every level of its stagger leaves the content box, so layout draws no marker there; the message names its pin and page. No call clears this: send the smallest model that shows it.
MISSING_JUNCTION_DOT ERROR render Fransys Three or more ink directions meet at a wire end or vertex with no dot and no pin, so the page does not show the wires joined or apart. No call clears this: send the smallest model that shows it. The message names the page.
NET_NOT_DRAWN ERROR render consumer A net of two or more ends has under two drawn pins, so it is left out. A lone pin gives none. The message names the port. Give the net a second drawn pin. Write: d.series(a, )
NOT_SERIES_PARALLEL INFO render note The named symbols are wired as a bridge, which no series or parallel holds. Nothing is wrong; the symbols stay drawn, and CONNECTION_NOT_DRAWN names each wire of the bridge left undrawn.
NO_BLOCK ERROR render consumer A box is drawn but belongs to no block, or to more than one, so layout places it by no rule; the message names it. Wire to one function block, or remove it. Write: d.series(a, b, ...) to draw it in a block.
NO_CELL WARNING render Fransys A symbol is drawn but stands in no cell of any column, or in more cells than it has elements, so layout places it by no rule; the message names it. No call clears this: report it with the smallest model that shows it.
ORDER_HINT_UNMET WARNING render consumer An authored order hint names two groups that are not on the same drawing set, so no page order can honour it. Move both groups onto one drawing set, or drop the hint. Write: d.layout.order(a, b) for groups on one drawing set.
OUTLINE_NO_ROOM WARNING render consumer A nested unit stands on its parent's page, but its frame does not fit the page or would hold another unit's symbol; the unit is drawn with no frame. Move the unit's devices together on the page, or give the unit its own page. Write: d.function(name, text) to place each device in one group.
OUT_OF_PAGE WARNING render Fransys A symbol body or a text lies outside the content box of its page. No call clears this: report it with the smallest model that shows it.
OVERLAP WARNING render Fransys Two drawn boxes (symbol bodies, and symbols drawn at a pin end such as a power symbol), a text and a body, two texts, or a wire and a text meet on one page; the message names the first of them. No call clears this: every fact is drawn and only the looks suffer. Report it with the smallest model that shows it. The message names the page and the members.
OVERVIEW_UNPLACED ERROR render Fransys The overview placer found no room plan for one view of the system overview, so the page would have no positions for it. No call clears this: send the smallest model that shows it.
PAGE_OVERFLOW ERROR render consumer A row of one block is taller than the page, so it stands on a page of its own. The message names the drawing set, the page and the devices standing in the row. Split into smaller function blocks, or use a taller sheet. Write: [paper] default = "A2" in the settings file, passed as fr.build(settings=fr.settings(path))
PIN_MARKING_WRONG ERROR render Fransys A symbol prints at a pin a marking other than the one the model gives that port, or prints none where the port is marked, or one where it is not. No call clears this: send the smallest model that shows it. The message names the page.
PLACEMENT_PROBLEM ERROR render Fransys The placement core cannot take the design, or a set of it; the set draws no page. The message names the thing and what the core expected. No call clears this: send the smallest model that shows it.
POWER_SYMBOL_NOT_JOINED ERROR render Fransys A power symbol is drawn for a pin with no wire to it and not on the pin, so the page does not show the pin on its rail. No call clears this: send the smallest model that shows it. The message names the page.
RAIL_IDENTITY_SHARED ERROR render consumer Two unbonded nets of a cabinet print one rail identity (its flagged rail, else the cabinet plus the printed potential), so the page would join nets the model keeps apart. No call clears this: two nets print one supply name with no protective device (fuse, breaker) between them, or the nearest device is not unique: put a fuse or breaker between them.
REFERENCE_NOT_READABLE ERROR render Fransys A reference marker is not drawn as the model gives it: it prints a text other than the one derived, stands in another cell than the stored one, stands on no wire of its net, or one reference number names two groups in one drawing set. A reader of the page then cannot find the other end. No call clears this: send the smallest model that shows it. The message names the page.
REFERENCE_OFF_DOCUMENT WARNING render consumer A printed reference points to a page that no page of its own document holds, and its text names no document, so a reader cannot tell which document to open. The message names the reference, its page and the target page. Print both drawing sets in one document, or print the target's drawing set in a document so the reference names it. Write: fr.document(, , cover=)
ROUTE_WRONG_PORT ERROR render Fransys A wire of one lane ends on a port of one net and on a port of another net. No call clears this: send the smallest model that shows it. The message names the page.
SET_WITHOUT_PAGE ERROR render consumer A drawing set holds symbols but every net of them has its other end in another set, so the core path gives it no page. The message names the set. Put the set's functions in the unit and location of the functions they are wired to. Write: d.device("K1", "DEMO-RLY-2CO-24", place="R") with the same place.
SPARE_FUNCTIONS INFO render note A function on no net, on an item that has other wired functions or declared unused=, is a spare: it is left off the schematic. One finding per document names the count and the items. Nothing is wrong; wire the function if it is not a spare.
SPARE_TERMINALS INFO render note A terminal none of whose nets has a second end is a spare: it stands in the terminal list and is not drawn on the schematic. One finding per document names the count and the strips. Nothing is wrong; wire the terminal if it is not a spare.
SYMBOL_PORT_MISSING ERROR render consumer A model port matches no port on its drawn symbol by any of the three binding rules. Fix the part's port names, or map them with symbol_port keys. Write: symbol_port = 'in' on the port in the part file.
TAG_ACROSS_BODY WARNING render consumer A net joins a pin on one half of a generic box to a column of parts hung on its other half, so it is drawn as a tag pair, not a wire round the box (CROSS-HALF-TAGS). Wire the parts to the box pins in one path. Write: d.series(, )
TITLE_BLOCK_NOTICE_OVERFLOW WARNING render consumer The notice text passed to fr.document(notice=) does not fit the notice cell and would be cut. Shorten the notice of to fit its cell. Write: fr.document(, , cover=, notice=)
TITLE_BLOCK_NO_ROOM WARNING render consumer The sheet format's title-block band is under the required 20mm, or its title block is under the required 97.5mm wide. Use a sheet format with a taller title-block band or a wider title block. Write: [paper] default = "A2" in the settings file, passed as fr.build(settings=fr.settings(path))
TITLE_BLOCK_STACK_OVERLAP ERROR render consumer The profile's text height needs a taller title-block band than the sheet format has, so a title-block label overlaps its value. Use a sheet format whose title-block band is at least the named height, or the house text height. Write: [paper] default = "A2" in the settings file, passed as fr.build(settings=fr.settings(path))
TITLE_BLOCK_TEXT_OVERFLOW WARNING render consumer A one-line title-block field (title, number, customer, revision, date, author, page title, scope or sheet counter) does not fit its cell. Shorten the field the message names. Write: d.project(title=, number=, customer=, revision=, author=) for the title, number, customer, revision or author, or d.function(, ) for a page title: the text of a block the page draws.
UNKNOWN_SYMBOL_KEY ERROR el consumer A function's chosen symbol key is not in the installed symbol library; it is drawn as a generic box. Fix the symbol key of in its rule, choice or part data, or install a library version that has it. Write: symbol = '' in the part file.
UNPRINTED_SET ERROR render consumer A drawing set has pages but no document prints it, so its items are not in any export. The message names the set and its items. Add a document for the set's unit or location, passing its handle as the subject, or nest the unit in one that has one. Write: fr.document(fr.DocumentPreset.CABINET_SCHEMATIC, cabinet, cover=cover)
WIDER_THAN_PAGE ERROR render consumer A row of columns is wider than the page even at its closest spacing. The message names the drawing set, the page and the devices standing in the row. Split the device over two units, or choose paper A2. Write: [paper] default = "A2" in the settings file, passed as fr.build(settings=fr.settings(path)).
WIRE_AS_REFERENCE INFO render consumer No orthogonal path on the wiring grid could be found for a connection, so it is drawn as a reference at its pin. None needed: the connection is shown by its reference. To draw it as a wire, give its ports more room.
WIRE_MEETS_NET WARNING render consumer A fixed wire (a lane wire, join, trunk or drop) meets another net's wire and no detour exists, so it is drawn as placed; the message names the wire and its ends. Move a symbol of or widen the gap beside it so the wire has a free path. Write: d.add(unit, tag) to move the device into a unit.
WIRE_NOT_ORTHOGONAL ERROR render Fransys A drawn wire has a segment that is neither horizontal nor vertical. No call clears this: send the smallest model that shows it. The message names the page.
WIRE_OVER_MARKER WARNING render Fransys A wire or a junction dot meets the box of a reference marker on one page, or a wire ends in it; the message names the first of them. No call clears this: every fact is drawn and only the looks suffer. Report it with the smallest model that shows it. The message names the page and the members.
WIRE_OVER_PIN_TIP ERROR render Fransys A wire passes over the tip of a pin with its interior and no dot, so the page does not show whether it joins the pin. No call clears this: send the smallest model that shows it. The message names the page.
WIRE_THROUGH_BODY ERROR render consumer A trunk is drawn through the drawn body of a symbol, or along its outline (a touch at a point or in its margin is not this error); the message names the net and the symbol. No call clears this: send the smallest model that shows it. A wire never passes a symbol's body, so the model shows a drawing fault.
