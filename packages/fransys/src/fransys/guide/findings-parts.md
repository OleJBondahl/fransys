# Finding codes: part files

> Offline copy. Read the official docs for your version at https://olejbondahl.github.io/fransys/X.Y.Z/ (X.Y.Z is `fransys.__version__`), or https://olejbondahl.github.io/fransys/X.Y.Z/llms.txt. Use this copy only offline.

Codes the part-file lint emits, at `fr.lint` and when `fr.design` or `fr.parts` loads a library. Who acts is explained in [`findings.md`](findings.md).

| Code | Severity | Stage | Who acts | Meaning | Fix |
| --- | --- | --- | --- | --- | --- |
| BAR_SYMBOL | ERROR | library load | part author | A `bar` function names a `symbol`; a bar is never drawn. | Remove the function's `symbol` key. |
| BOARD_WITHOUT_PCB | WARNING | library load | part author | A part with `category = "board"` has no `[pcb]` table. | Add a `[pcb]` table with a `revision` string, or change `category` to the part's real category. |
| CABLE_PAIR_INVALID | ERROR | library load | part author | A `[cable_product]` `pairs` entry breaks a pair rule: a core is out of range, in two pairs, or `SH`, or a `screen` is not a unique `SH` core. | Give each `pairs` entry two integer `cores` in range, none `SH` and none in another pair, and a `screen` that is one unique `SH` core. |
| CABLE_WITHOUT_PRODUCT | ERROR | library load | part author | A part with `category = "cable"` has no `[cable_product]` table, or a part with another category has one. | Add a `[cable_product]` table to a cable part, or remove `[cable_product]` from a part whose `category` is not `cable`. |
| CHANGEOVER_LINK | ERROR | library load | part author | A `switched` link of a `contact_co` function joins two ports whose roles are not `common` with `break` or `make`. | Make each `switched` link of the `contact_co` function join a `common` port to a `break` or `make` port. |
| CHANGEOVER_ROLE | ERROR | library load | part author | A port of a `contact_co` function has a `role` other than `common`, `break` or `make`. | Set that port's `role` to `common`, `break` or `make`. |
| CHANGEOVER_SYMBOL_PORT | ERROR | library load | part author | A port of a `contact_co` function sets `symbol_port`. | Remove `symbol_port` from the `contact_co` port; the drawing binds a changeover by its throw roles. |
| CLASS_CODE | ERROR | library load | part author | `class_code` is not 1 to 3 uppercase letters, starts with A, I or O, or starts with D, L, V, Y or Z. | Set `class_code` to 1 to 3 uppercase letters, first letter as in IEC 81346-2, such as `K` or `QA`. |
| CONNECTOR_MARKING_REUSED | ERROR | library load | part author | Two connector functions of one part print the same label, their `marking` or else their `name`. | Give one connector function a different `marking` under `[function.connector]`, or a different `name`. |
| CONTACT_WITHOUT_SWITCHED_LINK | ERROR | library load | part author | A `contact_no`, `contact_nc`, `contact_co` or `switch` function has no `switched` link in its `links`. | Add a `links` entry with `kind = "switched"` joining its ports, or change the function's `kind`. |
| ENERGY_ON_NON_POWER | ERROR | library load | part author | A function whose `kind` is not `supply` or `load` sets `energy`. | Remove `energy` from the function, or change its `kind` to `supply` or `load`. |
| ENUM_VALUE | ERROR | library load | part author | A field typed as an enum holds a string that is no member of that enum. | Set the field to one of the values the message lists, such as a `kind` or `role` value. |
| FACET_KIND_MISMATCH | ERROR | library load | part author | A `[function.connector]` sits on a function whose `kind` is not `connector`, or a `[function.plc_channel]` on one whose `kind` is not `plc_channel`. | Change the function's `kind` to match the sub-table, or move the sub-table to the right `[[function]]`. |
| FIELD_MISSING | ERROR | library load | part author | A required key is absent: the file's `schema`, its `[part]` table, or a required field of a table. | Add the `schema = 1` line, the `[part]` table, or the required field the message names. |
| FIELD_TYPE | ERROR | library load | part author | A value has a TOML type the contract does not allow there, such as an integer for a quantity or a table where a list belongs. | Write the value as the type the message names, such as a quoted string for a rating or an integer for `schema`. |
| FIELD_UNKNOWN | ERROR | library load | part author | A table holds a key the part-file contract does not name for that table. | Remove the key, or correct its spelling to a field the part-file contract names. |
| FILE_NAME | WARNING | library load | part author | A part file's name has characters other than lowercase letters, digits, hyphens and underscores. | Rename the file using only lowercase letters, digits, hyphens and underscores. |
| FUNCTION_NAME_DUPLICATE | ERROR | library load | part author | Two `[[function]]` entries of one part have the same `name`. | Give one of the functions a different `name`. |
| FUNCTION_WITHOUT_PORTS | ERROR | library load | part author | A `[[function]]` other than a `bar` has an empty `ports` list. | Add at least one entry to the function's `ports` array, or remove the function. |
| JOIN_INTO_CONNECTOR | ERROR | library load | part author | A header pin's `joins` names a port of a `connector` function. | Point `joins` at a port of a non-connector function of the same part. |
| JOIN_PORT_TWICE | ERROR | library load | part author | Two header pins of one part both `joins` the same function port. | Remove the `joins` from one of the two header pins, or point it at a different port. |
| JOIN_PORT_UNKNOWN | ERROR | library load | part author | A header pin's `joins` value does not name a port of a function in this part, or is not `<function>.<port>`. | Set `joins` to `<function>.<port>` naming an existing port of another function of this part. |
| LIBRARY_FILE_MISSING | ERROR | library load | part author | The library root has no `library.toml` file. | Add `library.toml` at the library package root with `schema`, `name` and `version`. |
| LINK_DUPLICATE | ERROR | library load | part author | Two `links` entries of one function join the same pair of ports, in either order. | Remove the repeated `links` entry. |
| LINK_PORT_UNKNOWN | ERROR | library load | part author | A `links` entry's `a` or `b` is not a `name` in the function's `ports`. | Set `a` and `b` to names from the function's `ports`, or add the missing port. |
| LINK_SELF | ERROR | library load | part author | A `links` entry has the same port as `a` and `b`. | Set `b` to a different port from `a`. |
| PART_DUPLICATE | ERROR | library load | part author | Two part files declare the same `manufacturer` and `mpn` pair. | Remove one of the files, or correct the `mpn` or `manufacturer` of the one declared in error. |
| PINCOUNT | ERROR | library load | part author | A `[function.connector]` has a `pincount` below 1. | Set `pincount` to 1 or more. |
| PLC_CHANNEL_DUPLICATE | ERROR | library load | part author | Two `[function.plc_channel]` tables of one part have the same `channel` and `signal`. | Give one of the channels a different `channel` number, or a different `signal`. |
| PORT_NAME_DUPLICATE | ERROR | library load | part author | Two ports of one function have the same `name`. | Rename one of the ports so each port name in the function is unique. |
| PORT_NAME_SHARED | ERROR | library load | part author | Two functions of one part give a port the same name, and their printed designations would be the same. | Rename the port on one of the two functions so the printed designations differ. |
| POWER_LOSS_TWICE | ERROR | library load | part author | `power_loss_w` is set both in the part's `[rating]` and in a function's `[function.rating]`. | Keep `power_loss_w` in one place: remove it from `[rating]` or from the `[function.rating]` it repeats. |
| PROTECTION_LINK_KIND | ERROR | library load | part author | A `switched` link sits on a `protection` function, or a through link's `kind` does not fit its protection `type`. | Use `kind = "protective"` for fuse, mcb, motor_breaker and rcd, and `kind = "conductive"` for overload; never `switched`. |
| PROTECTION_TYPE_ON_NON_PROTECTION | ERROR | library load | part author | A function whose `kind` is not `protection` has a `[function.protection]` table with a `type`. | Remove the `[function.protection]` table, or change the function's `kind` to `protection`. |
| PROTECTION_WITHOUT_TYPE | WARNING | library load | part author | A `protection` function has no `type` in its `[function.protection]` table. | Add `type` to `[function.protection]`, one of fuse, mcb, motor_breaker, overload or rcd. |
| RATING_TABLE_EMPTY | ERROR | library load | part author | A `[rating]`, `[function.rating]` or `[function.operating]` table has no field. | Add at least one value to the table, or delete the table. |
| RATING_VALUE_INVALID | ERROR | library load | part author | A rating value is not a plain decimal string, is zero where a rating needs a positive value, or a breaking point list is malformed. | Write each value as a quoted plain decimal such as "24", above zero in ratings, and each breaking point with `voltage_v` and `current_a`. |
| REST_DISAGREES_WITH_KIND | ERROR | library load | part author | A switched link's `rest` disagrees with its function's `kind`: `contact_no` is open at rest, `contact_nc` is closed. | Set `rest` to match `kind`, `open` for `contact_no` and `closed` for `contact_nc`, or change `kind`. |
| REST_ON_UNSWITCHED_LINK | ERROR | library load | part author | A link whose `kind` is not `switched` sets `rest`. | Remove `rest` from the link, or change its `kind` to `switched`. |
| SCHEMA_MIXED | ERROR | library load | part author | A part file's `schema` differs from the `schema` in its library's `library.toml`. | Set the file's `schema` to the value `library.toml` names, or change `library.toml` and every file in one commit. |
| SCHEMA_UNSUPPORTED | ERROR | library load | part author | A `schema` value is not in `SUPPORTED_SCHEMAS`, which today holds only 1. | Set `schema = 1`, the only supported value today. |
| SWITCHED_LINK_WITHOUT_REST | ERROR | library load | part author | A `switched` link of a `switch` or `generic` function sets no `rest`. | Add `rest = "open"` or `rest = "closed"` to the link. |
| SYMBOL_PORT_WITHOUT_SYMBOL | ERROR | library load | part author | A port sets `symbol_port`, but its function has no `symbol`. | Add a `symbol` to the function, or remove `symbol_port` from the port. |
| SYMBOL_REST_MISMATCH | ERROR | library load | part author | A function's `symbol` implies a rest state (`make-contact` open; `break-contact` and `emergency-stop` closed), and its switched links, stated or implied by its `kind`, are all at the other one. | Change the `symbol`, or the `rest` of the switched links, so both name the same rest state. |
| SYMBOL_SLUG | ERROR | library load | part author | A function's `symbol` is not a lowercase, hyphenated slug. | Rewrite `symbol` in lowercase letters and digits, joined by single hyphens, such as `change-over-contact`. |
| SYMBOL_TYPE_MISMATCH | ERROR | library load | part author | A protection function's `symbol` is `fuse` or `circuit-breaker`, but its protection `type` is another one. | Make `type` match the symbol: `fuse` for `fuse`, `mcb` for `circuit-breaker`, or change the `symbol`. |
| TABLE_UNKNOWN | ERROR | library load | part author | The file has a top-level table that is neither `schema` nor a part-file table the contract names. | Remove the table, or rename it to a table the part-file contract names. |
