Finding codes: part files

Codes the part-file lint emits, at fr.lint and when fr.design or fr.parts loads a library. Who acts is explained in findings.md.

Code Severity Stage Who acts Meaning Fix
BOARD_WITHOUT_PCB WARNING library load part author A part with category = "board" has no [pcb] table. A board has a [pcb] table with a string revision, or a category other than board. Write: revision = "A"
CABLE_PAIR_INVALID ERROR library load part author A [cable_product] pairs entry breaks a pair rule: a core is out of range, in two pairs, or SH, or a screen is not a unique SH core. Each pairs entry has two integer cores in range, neither SH nor in another pair, and a screen that is one unique SH core. Write: pairs = [{ cores = [1, 2], screen = 3 }]
CABLE_PRODUCT_CORE_COUNT ERROR library load part author A cable product's core_count differs from the number of its core_colours. Make core_count equal the number of core_colours. Write: core_colours = ["BN", "BU"]
CABLE_WITHOUT_PRODUCT ERROR library load part author A part with category = "cable" has no [cable_product] table, or a part with another category has one. A category = "cable" part has a [cable_product] table, and no other part does. Write: [cable_product]
CHANGEOVER_LINK ERROR library load part author A switched link of a contact_co function joins two ports whose roles are not common with break or make. Each switched link of a contact_co joins its common port to a break or make port. Write: links = [{ a = "11", b = "12", kind = "switched" }]
CHANGEOVER_ROLE ERROR library load part author A port of a contact_co function has a role other than common, break or make. A contact_co port takes the role common, break or make. Write: role = "common"
CHANGEOVER_SYMBOL_PORT ERROR library load part author A port of a contact_co function sets symbol_port. A contact_co port takes no symbol_port, since its throw roles bind the drawing. Write: { name = "12", role = "break" }
CLASS_CODE ERROR library load part author class_code is not 1 to 3 uppercase letters, starts with A, I or O, or starts with D, L, V, Y or Z. Use 1 to 3 uppercase letters, the first as in IEC 81346-2, such as K or QA. Write: class_code = "K"
CONNECTOR_MARKING_REUSED ERROR library load part author Two connector functions of one part print the same label, their marking or else their name. Each connector prints its own label, its marking or else its name. Write: marking = "X2"
CONTACT_WITHOUT_SWITCHED_LINK ERROR library load part author A contact_no, contact_nc, contact_co or switch function has no switched link in its links. A contact or switch function has a switched link joining two of its ports, or a different kind. Write: links = [{ a = "1", b = "2", kind = "switched" }]
ENERGY_ON_NON_POWER ERROR library load part author A function whose kind is not supply or load sets energy. Only a supply or load function takes energy. Write: kind = "load"
ENUM_VALUE ERROR library load part author A field typed as an enum holds a string that is no member of that enum. The field takes one of the values the message lists, spelled as the contract gives them. Write: kind = "load"
FACET_KIND_MISMATCH ERROR library load part author A [function.connector] sits on a function whose kind is not connector, or a [function.plc_channel] on one whose kind is not plc_channel. A [function.connector] needs kind = "connector", and a [function.plc_channel] needs kind = "plc_channel". Write: kind = "connector"
FIELD_MISSING ERROR library load part author A required key is absent: the file's schema, its [part] table, or a required field of a table. Each file needs schema, its [part] table and each required field, with values the contract allows. Write: schema = 2
FIELD_TYPE ERROR library load part author A value has a TOML type the contract does not allow there, such as an integer for a quantity or a table where a list belongs. Write the value as the type the message names, a quoted string for a rating or an integer for schema. Write: schema = 2
FIELD_UNKNOWN ERROR library load part author A table holds a key the part-file contract does not name for that table. A table takes only the keys the part-file contract names for it. Write: =
FILE_NAME WARNING library load part author A part file's name has characters other than lowercase letters, digits, hyphens and underscores. A part file name uses only lowercase letters, digits, hyphens and underscores. Write: relay-2co-24vdc.toml
FUNCTION_NAME_DUPLICATE ERROR library load part author Two [[function]] entries of one part have the same name. Each [[function]] has its own name. Write: name = "co_3"
FUNCTION_WITHOUT_PORTS ERROR library load part author A [[function]] has an empty ports list. A [[function]] lists at least one port in ports. Write: ports = [{ name = "1", role = "generic" }]
JOIN_INTO_CONNECTOR ERROR library load part author A header pin's joins names a port of a connector function. A header pin joins a port of a non-connector function of the same part. Write: joins = "k1.A1"
JOIN_PORT_TWICE ERROR library load part author Two header pins of one part both joins the same function port. Each function port is joined by at most one header pin. Write: joins = "k1.A2"
JOIN_PORT_UNKNOWN ERROR library load part author A header pin's joins value does not name a port of a function in this part, or is not <function>.<port>. joins is <function>.<port>, naming a port of another function of this part. Write: joins = "k1.A1"
LIBRARY_FILE_MISSING ERROR library load part author The library root has no library.toml file. The library root holds a library.toml with schema, name and version. Write: schema = 2
LINK_DUPLICATE ERROR library load part author Two links entries of one function join the same pair of ports, in either order. Each pair of ports is linked once in a function, in either order. Write: links = [{ a = "11", b = "12", kind = "switched" }]
LINK_PORT_UNKNOWN ERROR library load part author A links entry's a or b is not a name in the function's ports. Each a and b names a port listed in ports. Write: a = "11"
LINK_SELF ERROR library load part author A links entry has the same port as a and b. a and b name two different ports. Write: b = "12"
PART_DUPLICATE ERROR library load part author Two part files declare the same manufacturer and mpn pair. Each manufacturer and mpn pair is declared by one part file only. Write: mpn = "DEMO-RLY-2CO-24"
PART_SCHEMA_OLD ERROR library load part author A part file or library.toml is written in schema 1. Run python -m fransys migrate-parts DIR on the library folder; it rewrites each schema 1 file to schema 2. Write: schema = 2
PINCOUNT ERROR library load part author A [function.connector] has a pincount below 1. A connector pincount is an integer of 1 or more. Write: pincount = 2
PLC_CHANNEL_DUPLICATE ERROR library load part author Two [function.plc_channel] tables of one part have the same channel and signal. Each [function.plc_channel] has its own channel and signal. Write: channel = 4
PORT_NAME_DUPLICATE ERROR library load part author Two ports of one function have the same name. Each port of one function has its own name. Write: name = "A2"
PORT_NAME_SHARED ERROR library load part author Two functions of one part give a port the same name, and their printed designations would be the same. Each port name is unique across the part, so the printed designations differ. Write: name = "A3"
POWER_LOSS_TWICE ERROR library load part author power_loss is set both in the part's [rating] and in a function's [function.rating]. power_loss is stated once, in [rating] or in one [function.rating]. Write: power_loss = { nom = "2.5 W" }
PROTECTION_LINK_KIND ERROR library load part author A switched link sits on a protection function, or a through link's kind does not fit its protection type. A fuse, mcb, motor_breaker or rcd link is protective, an overload link is conductive, never switched. Write: kind = "protective"
PROTECTION_TYPE_ON_NON_PROTECTION ERROR library load part author A function whose kind is not protection has a [function.block] table with a type. Only a protection function has a [function.block] table with a type. Write: kind = "protection"
PROTECTION_WITHOUT_TYPE WARNING library load part author A protection function has no type in its [function.block] table. [function.block] needs a type: fuse, mcb, motor_breaker, overload or rcd. Write: type = "mcb"
RATING_TABLE_EMPTY ERROR library load part author A [rating], [function.rating] or [function.operating] table has no field. A rating table holds at least one value, or the table is deleted. Write: voltage = [{ nom = "24 V", at = ["DC"] }]
RATING_VALUE_INVALID ERROR library load part author A figure or quantity is not written as schema 2 asks: a quantity is a number, a space and a unit symbol, and a figure an inline table. Write each quantity as a string such as "24 V", above zero in a rating, and each figure as an inline table. Write: voltage = [{ nom = "24 V", at = ["DC"] }]
REST_DISAGREES_WITH_KIND ERROR library load part author A switched link's rest disagrees with its function's kind: contact_no is open at rest, contact_nc is closed. rest is open for contact_no and closed for contact_nc, or change kind. Write: rest = "open"
REST_ON_UNSWITCHED_LINK ERROR library load part author A link whose kind is not switched sets rest. Only a switched link takes rest. Write: kind = "switched"
SCHEMA_MIXED ERROR library load part author A part file's schema differs from the schema in its library's library.toml. The file's schema is the value library.toml names, or both change in one commit. Write: schema = 2
SCHEMA_UNSUPPORTED ERROR library load part author A schema value is not in SUPPORTED_SCHEMAS, which today holds only 2. The schema is an integer in the supported set, only 2 today. Write: schema = 2
SWITCHED_LINK_WITHOUT_REST ERROR library load part author A switched link of a switch or generic function sets no rest. A switched link of a switch or generic function states its rest. Write: rest = "open"
SYMBOL_PORT_WITHOUT_SYMBOL ERROR library load part author A port sets symbol_port, but its function has no symbol. A port with symbol_port needs its function to have a symbol. Write: symbol = "operating-device"
SYMBOL_REST_MISMATCH ERROR library load part author A function's symbol implies a rest state (make-contact open; break-contact and emergency-stop closed), and its switched links, stated or implied by its kind, are all at the other one. The symbol and the switched links agree on one rest state: make-contact is open, break-contact and emergency-stop are closed. Write: rest = "open"
SYMBOL_SLUG ERROR library load part author A function's symbol is not a lowercase, hyphenated slug. symbol is lowercase letters and digits joined by single hyphens, such as change-over-contact. Write: symbol = "change-over-contact"
SYMBOL_TYPE_MISMATCH ERROR library load part author A protection function's symbol is fuse or circuit-breaker, but its protection type is another one. A fuse symbol needs type = "fuse", a circuit-breaker symbol needs type = "mcb". Write: type = "fuse"
TABLE_UNKNOWN ERROR library load part author The file has a top-level table that is neither schema nor a part-file table the contract names. A top-level table is schema or a table the part-file contract names. Write: [part]
