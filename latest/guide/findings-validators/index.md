# Finding codes: validators, build and release

Codes the model checks and the library load emit. Who acts is explained in [`findings.md`](../findings/index.md).

| Code | Severity | Stage | Who acts | Meaning | Fix |
| --- | --- | --- | --- | --- | --- |
| ASPECT_CROSS_PARENT | ERROR | validators | consumer | An aspect node's parent belongs to a different aspect (function, location or product). | Give each location a parent of its own aspect, a location. Write: d.location("BATT", "Battery bay", within="HOLD") |
| ASPECT_CYCLE | ERROR | validators | consumer | An aspect node's parent chain loops back on itself. | Make the parents of locations form a tree, never a loop. Write: d.location("BATT", "Battery bay", within="HOLD") |
| BOUNDARY_NOT_IN_UNIT | ERROR | validators | consumer | A unit's boundary function belongs to an item outside that unit's subtree. | Declare as the unit's boundary only a function of an item built inside that unit. Write: d.device("X1", "DEMO-CONN-2P", interface=True) |
| BOUNDARY_UNCONNECTED | ERROR | validators | consumer | A unit's boundary function is not connected across the unit nor declared unused. | Wire each boundary function across the unit, or declare it unused on purpose: inside the unit for its own fact, d.device("X2", "DEMO-CONN-2P", interface=True, unused=True); in the design that adds it for a point it leaves to another carrier. Write: d.unused(pc.x3[3], pc.x4_1) |
| CABLE_CORES_FEWER | WARNING | validators | consumer | A cable item carries fewer cores than its product has core colours. | Use as many cores as the product has colours, each wired or marked spare. Write: W1.spare() |
| CABLE_CORES_MORE | ERROR | validators | consumer | A cable item carries more cores than its product has core colours. | Use as many cores as the product has colours, each wired or marked spare. Write: W1.spare() |
| CONDUCTOR_ON_UNINSTALLED | WARNING | validators | consumer | A conductor lands on an item that is not marked installed. | Mark the item installed, or remove the conductor that lands on it. Write: d.device("Q9", "DEMO-MCB-3P") |
| CONNECTOR_WIRED_WITHOUT_MATE | WARNING | validators | consumer | A conductor from outside a nested unit lands directly on its boundary connector, whose part gender is male or female (genderless or unstated passes). | End a cable's cores at the connector's pins. Write: d.cable("W1", P.CBL).core(1, plug[1], connector[1]) |
| CONTAINMENT_CYCLE | ERROR | validators | consumer | An item's physical-containment parent chain loops back on itself. | Make physical containment a tree: no item sits inside itself. Write: d.device("X1", "DEMO-CONN-2P", parent=k1) |
| CORE_INDEX_PAST_PRODUCT | ERROR | validators | consumer | A cable core is numbered past the core count of the cable's product. | Number the cores from 1 to the product's core count. Write: W1.core(3, x1[1], x1[2]) |
| CORE_ON_PE_NOT_GNYE | ERROR | validators | consumer | A cable core that is not green-yellow (GNYE) lands on a port with role PE; a screen core (`SH`) is exempt. | The PE core is GNYE (IEC 60204-1): land the GNYE core on the PE port, and another core elsewhere. Write: W1.core(GNYE, a, b) |
| DESIGNATION_DUPLICATE | ERROR | build | consumer | Two items or unit instances under one parent print one designation: a tag equal to a sibling's text, or a retired or moved released one. | Give each item or unit instance under one parent its own tag, one no released revision reserved. Write: d.device("X2", "DEMO-CONN-2P") |
| DESIGNATION_MOVED | ERROR | release | consumer | An item or unit instance pinned in the previous release now prints a different designation, written or numbered. | No call clears this: restore the released tag on <subject>; only a new version may change it. |
| DESIGNATION_NEW_IN_REVISION | INFO | build, release | note | A new untagged item or unit instance took the next free number in a later revision. | Nothing is wrong; tag it if its number must stay fixed. |
| DOCUMENT_UNIT_UNRESOLVED | ERROR | validators | consumer | A document's `unit_name` matches no unit, or more than one. | Document each placement with what `d.add` returned; the unit's own PDF comes from its release write. Write: fr.document(fr.DocumentPreset.CABINET_SCHEMATIC, placed, cover=Path("cover.md")) |
| FILE_UNREADABLE | ERROR | library load | consumer | A part-file could not be read (missing file, permission error, or bad encoding). | No call clears this: fix the path, the file permissions or the UTF-8 encoding, then load again. |
| FLOAT_FORBIDDEN | ERROR | library load | consumer | A part-file has a bare TOML float, which the contract forbids (quote values as strings). | A number is a quoted string in a part file, never a bare TOML float. Write: nominal_current = "24.5 A" |
| FUNCTION_HALF_CONNECTED | ERROR | validators | consumer | A two-port coil, load, contact, switch, protection or actuator is connected at one port and open at the other. | Wire both ports of the function. Write: d.series(a, b) |
| GNYE_NOT_PE_DECLARED | ERROR | validators | consumer | A green-yellow conductor is on a net that a declared net lists and that is not PE (IEC 60445 keeps green-yellow for PE). | Use green-yellow only on the PE net, which `d.earth` declares. Write: d.earth(*pins) |
| GNYE_NOT_PE_UNDECLARED | WARNING | validators | consumer | A green-yellow conductor is on a net that is not PE and that no declared net lists (IEC 60445 keeps green-yellow for PE). | Use green-yellow only on the PE net, which `d.earth` declares. Write: d.earth(*pins) |
| HARNESS_END_AMBIGUOUS | ERROR | build | consumer | Two or more ends of one cable print the same text in its drawing. | Give each cable end its own text with distinct locations or distinct tags. Write: d.device("X2", "DEMO-CONN-2P", place="A2") |
| HARNESS_HOLDS_PLC_MODULE | ERROR | validators | consumer | A PLC module sits under an item made with `d.harness`. | Put the PLC modules under a rack, not a harness, so they print flat. Write: d.rack("U1", name="plc") |
| HARNESS_WITHOUT_TAG | ERROR | validators | consumer | A harness (marked, or with a cable child) has no tag or assigned designation, so it has no label. | Give the harness a tag so it has a label. Write: d.harness("W5") |
| ITEM_PART_MISMATCH | ERROR | validators | consumer | An item's functions or ports do not match its part's templates (missing, extra, duplicated, or differing in name, kind, role or marking). | Make the item's functions and ports match its part's templates, by building it from the part as it stands. Write: d.device("Q1", "DEMO-MCB-3P") |
| ITEM_WITHOUT_PART | INFO | validators | note | A non-external item has no `part`, so its functions are authored directly, not checked against templates. | Usually nothing to fix: assign a `part` to check against templates. |
| LOADS_ABOVE_LIMIT | WARNING | validators | consumer | The loads one limit bounds sum above it; none is above it alone. | Lower the loads' summed draw below the limit, or split them across more limits. Write: nominal_current = "0.5 A" |
| LOAD_ABOVE_LIMIT | ERROR | validators | consumer | A load's stated draw is above the limit that bounds it. | Lower the load's stated draw below its limit, or raise the source's limit. Write: nominal_current_a = "0.5" |
| MATES_DISABLED | ERROR | validators | consumer | A mate or harness line is refused in 0.22. | Use a cable. Write: d.cable("W1", P.CBL) |
| MATE_NOT_CONNECTOR | ERROR | validators | consumer | A mate end is not a connector or terminal (a relay coil, say). | Mate only connector or terminal functions. Write: d.mate(plug, connector) |
| MATE_PORT_MISMATCH | ERROR | validators | consumer | A mate's two functions have different port names, so some ports have no counterpart. | Mate two connectors whose port names match, so every port has a counterpart. Write: d.mate(j1, j2) |
| MULTILINE_STRING | ERROR | library load | consumer | A part-file string contains a line break, which the contract forbids. | A string stays on one line; a line break is written as TOML's escaped `\n`. Write: description = "one line" |
| NET_ACROSS_UNIT_BOUNDARY_JOINED | WARNING | validators | consumer | A declared net joins pins in different units and no wire joins it, but every boundary pin has another way across; a net does not cross a unit boundary. | Join across the boundary with a wire, and keep nets inside one unit. Write: d.series(a, b, wire=...) |
| NET_ACROSS_UNIT_BOUNDARY_OPEN | ERROR | validators | consumer | A declared net joins pins in different units, no wire joins it, and a boundary pin has no other way across; a net does not cross a unit boundary. | Join across the boundary with a wire, and keep nets inside one unit. Write: d.series(a, b, wire=...) |
| NET_POTENTIAL_CONFLICT | ERROR | validators | consumer | One physical net joins two declared nets that are rails of different supply potentials. | No call clears this: remove the series that joins the two nets, or correct its ends. |
| NET_SHORTED | ERROR | validators | consumer | One physical net joins declared nets of different names. | No call clears this: remove the series that joins the two nets, or correct its ends. |
| NET_UNREALISED | ERROR | validators | consumer | A declared net's ports fall into more than one physical net, and no single board holds them all. Not for the PE net. | Put every port of the declared net on one board, or wire them into one net. Write: d.series(a, b) |
| ORDER_HINT_CYCLE | ERROR | build | consumer | Authored `d.layout.order` hints contradict each other in a cycle (a before b, b before a), so no page order can honour them. | Drop one hint of the cycle the message names. Write: d.layout.order(a, b) for one direction only |
| PART_LIBRARY_VERSION_CONFLICT | ERROR | library load | consumer | Two `PartLibrary` records share a name but declare different versions. | Load one version of each named part library. Write: fr.design("demo-parts") |
| PE_NOT_GNYE | WARNING | validators | consumer | A single wire on a PE net is not green-yellow (an empty colour is not a finding). | Colour a PE wire green-yellow. Write: d.series(a, b, wire=(fr.colours.GNYE, 0.75)) |
| PE_PORT_OFF_PE | WARNING | validators | consumer | A port with role PE is on a net that is not PE. | Put a port with role PE on the PE net. Write: d.earth(*pins) |
| PLACEMENT_DUPLICATE | ERROR | validators | consumer | One item is placed more than once in the same aspect (function, location or product). | Place each item once in each aspect. Write: d.device("X1", "DEMO-CONN-2P", place="A1") |
| PLC_BINDING_SIGNAL_MISMATCH | ERROR | validators | consumer | A PLC binding's channel does not have the signal type the request asked for (or is not a declared channel at all). The message names the asked kind, the channel, its kind and both fixes. | Bind the request to a channel of the signal type it asked for. Write: K1.coil.plc(fr.DO, "pump-run") |
| PLC_BINDING_WIRING_MISMATCH | ERROR | validators | consumer | A PLC binding disagrees with the wiring: the request or channel function is wired to a different channel or request than its binding. | Wire the request to the channel its binding names, or change the binding. Write: K1.coil.plc(fr.DO, "pump-run") |
| PLC_CHANNEL_CONTESTED | ERROR | build | consumer | Two or more PLC requests of the channel's signal are wired to the same channel. The finding names the channel's pins and every request; none of them binds, and none goes to the free queue. | Keep one PLC request per channel and wire each other request to a channel of its own. Write: d.series(k1.coil["A1"], a1.di_1) |
| PLC_REQUEST_AMBIGUOUS | ERROR | build | consumer | A PLC request is wired so that several free channels of its signal tie: its net reaches them all, or all by a direct conductor. It gets no binding. | Wire the request straight to one channel of its signal, or free the other channels. Write: d.series(k1.coil["A1"], a1.di_1) |
| PLC_REQUEST_UNSERVABLE | ERROR | build | consumer | No free PLC channel of the requested signal type on the request's unit chain (its unit declares none, or every one is taken). | Add a PLC module with a free channel of the requested signal type to the unit or a parent unit, or move another request off one. Write: d.device("A1", "DEMO-PLC-DI-16") |
| PORT_DESIGNATION_DUPLICATE | ERROR | build | consumer | Two or more ports of one item print the same designation text, so a drawing or list cannot tell them apart. | Give each port of one item its own printed pin marking in the part file. Write: marking = "A2" |
| POTENTIAL_IN_TWO_SUPPLIES | ERROR | validators | consumer | One potential name is a rail of two differently named supplies. | Declare each rail name in one supply only. Write: d.dc_supply("24VDC", d.device("G1", "DEMO-PSU-24")) |
| POTENTIAL_WITHOUT_SUPPLY | WARNING | validators | consumer | A net potential no supply declares: its pins get no rank and no power symbol. | Declare every net potential with a supply. Write: d.dc_supply("24VDC", d.device("G1", "DEMO-PSU-24")) |
| PRODUCT_DESIGNATION_DUPLICATE | ERROR | build | consumer | Two items print the same product designation (location plus own label): both at one location or, unplaced, both unnumbered alike in one unit instance. | Give each item a distinct location or label: place one elsewhere, or tag it. Write: d.device("X2", "DEMO-CONN-2P", place="A2") |
| RAIL_DUPLICATE_POTENTIAL | ERROR | validators | consumer | Two rail groups of one unit carry the same potential. | Flag one bridged group per potential in a unit. Write: x.run("24V", 4, bridged=True, rail=True) |
| RAIL_ON_FUSED | ERROR | validators | consumer | A rail group holds a terminal whose part has a protective link (a fuse in the path). | Flag the supply side of the fuse, not a fused terminal. Write: x.run("24V", 4, bridged=True, rail=True) |
| RAIL_WITHOUT_POTENTIAL | ERROR | validators | consumer | A rail group carries no power potential. | Declare the potential first, then flag the group. Write: d.dc_supply("S", plus=x[1], minus=y[1], voltage=24) |
| RATING_BREAKING_BELOW_FAULT | ERROR | validators | consumer | A protective device breaks less current than the prospective fault at its position. | Use a protective device that breaks more than the prospective fault current. Write: breaking_capacity = [{ nom = "15000 A", at = ["DC", "24 V"] }] |
| RATING_BREAKING_NO_DATA | WARNING | validators | consumer | A device states breaking points, but none covers the circuit voltage or time constant. | State a breaking point that covers the circuit voltage and time constant. Write: breaking_capacity = [{ nom = "15000 A", at = ["DC", "24 V", "10 ms"] }] |
| RATING_CURRENT_BELOW_BRANCH | ERROR | validators | consumer | A function's rated current is below the current its branch can carry. | Use a function rated for the current its branch can carry. Write: current = [{ nom = "16 A", at = ["DC"] }] |
| RATING_CURRENT_KIND_UNSTATED | WARNING | validators | consumer | A function's part states a voltage rating for AC or for DC only, and the function stands on rails of the other current kind. | State the part's voltage rating for the current kind of its rails. Write: voltage = [{ nom = "24 V", at = ["DC"] }] |
| RATING_VOLTAGE_BELOW_CIRCUIT | ERROR | validators | consumer | A function's rated voltage is below the voltage that stands across it. | Use a part rated for the voltage that stands across it. Write: voltage = [{ nom = "24 V", at = ["DC"] }] |
| REFERENCE_DESIGNATION_DUPLICATE | ERROR | build | consumer | Two items in the function or location aspect print the same full reference designation (e.g. two unit instances at one location). | Place the two items at different locations so their designations differ. Write: d.device("X2", "DEMO-CONN-2P", place="A2") |
| REVISION_CURRENT_MISSING | ERROR | validators | consumer | A unit's (or the project's) current revision has no matching `Revision` history entry, so a title block prints no date. | Add a history entry for the current revision. Write: d.revision(1, date="2026-01-01", text="first", created="AB") |
| REVISION_DATE_FORMAT | ERROR | validators | consumer | A revision entry's date is not in `YYYY-MM-DD` format. | Write each revision date as YYYY-MM-DD. Write: d.revision(1, date="2026-01-01", text="first", created="AB") |
| REVISION_INITIALS_MISSING | ERROR | validators | consumer | A revision entry has no `created` (author initials). | Give each revision entry its author's initials in `created`. Write: d.revision(1, date="2026-01-01", text="first", created="AB") |
| SCALING_NOT_ANALOGUE | ERROR | validators | consumer | A function with an engineering range has no PLC request, or requests a DI, DO or RELAY channel. | Scale only an analogue channel: request it with fr.AI, fr.AO or fr.SignalType.RTD. Write: fn.plc(fr.AI, "level").scale("%", raw=(4, 20), eng=("0", "100")) |
| SCALING_RANGE_INVALID | ERROR | validators | consumer | A channel's engineering or raw range has its low value at or above its high value. | Write the low value first, below the high value. Write: fn.plc(fr.AI, "level").scale("%", raw=(4, 20), eng=("0", "100")) |
| SCALING_UNIT_EMPTY | ERROR | validators | consumer | The unit of a channel's engineering range is blank or has several lines. | Name the unit, e.g. "%" or "bar". Write: fn.plc(fr.AI, "level").scale("%", raw=(4, 20), eng=("0", "100")) |
| STRIP_WITHOUT_TAG | ERROR | validators | consumer | A part-less top-level item, usually a floating strip, has no tag and no class code (no terminals, or disagreeing ones). | Give the strip a tag, a part, or terminals of one class code. Write: d.terminal_strip("X1", "DEMO-TB-2.5", 4) |
| SUPPLY_DIFFERS | ERROR | validators | consumer | Two declarations of one supply name disagree in current or rails. | Declare each supply name once, or twice with identical values. Write: d.dc_supply("24VDC", d.device("G1", "DEMO-PSU-24")) |
| TERMINAL_MORE_THAN_TWO_PINS | ERROR | validators | consumer | A terminal has over two ports. | Use a two-pin part. Write: d.terminal_strip("X1", "DEMO-TB-2.5", 2) |
| TERMINAL_POINT_OVERFILLED | ERROR | validators | consumer | A terminal point has more wires and cable cores than its part takes (conductors_per_clamp, default 1). | Use a part that takes more, or bridge a second terminal. Write: d.terminal_strip("X1", "DEMO-TB-2.5-TWIN", 2) |
| TOML_INVALID | ERROR | library load | consumer | A part-file is not valid TOML. | The file is valid TOML: fix the syntax error the message names. Write: name = "value" |
| UNIT_BOUNDARY_BYPASSED | ERROR | validators | consumer | A conductor or mate crosses out of a unit at a function that is not declared that unit's boundary. | Cross a unit's edge only at a function declared as its boundary. Write: d.device("X1", "DEMO-CONN-2P", interface=True) |
| UNIT_CYCLE | ERROR | validators | consumer | A unit's parent chain loops back on itself. | Nest units as a tree, adding each unit once. Write: d.add(cabinet, "U1") |
| UNUSED_CONTRADICTED | WARNING | validators | consumer | A function declared unused is wired, or is a unit boundary connected across the unit the declaration is on. | Declare unused only a function that is wired nowhere, and for a boundary not across its unit. Write: d.device("X2", "DEMO-CONN-2P", interface=True, unused=True) |
| UNUSED_NOT_BOUNDARY | ERROR | validators | consumer | A point named in d.unused is no boundary point of its nested unit. | List in d.unused only the boundary points a nested unit offers; remove this one. Write: d.unused(pc.x3[3]) |
| UNUSED_POINT_WIRED | ERROR | validators | consumer | A boundary point or a port named in d.unused is wired. | Drop the pin from d.unused, or its wire; list an interface pin in the carrier, not the unit. Write: d.unused(pc.x3[4]) |
| WIRE_COLOUR_UNKNOWN | ERROR | validators | consumer | A wire or cable-product core colour is not a recognized IEC 60757 colour code (or combination). | Use an IEC 60757 code: a base code, two combined, a base with a core number, or SH. Write: d.series(a, b, wire=(fr.colours.BU, 0.75)) |
| WIRE_ON_TWO_HARNESSES | ERROR | validators | consumer | A wire joins plugs of two harnesses. | Keep each wire within one harness, or join the two harnesses through a cable. Write: d.pair(a, w1, b) |
| WIRE_ROW_UNRESOLVED | ERROR | build | consumer | A series or detail wire was written without a row, and at build end its net carries no rail of its unit, states no `source_row` and holds no PLC channel signal, or carries rails of two rows. The message names the net and the wire's two pins. | Give the wire a (colour, size), or a size with a row table; a rail never crosses a unit boundary. Write: d.series(a, b, wire=(fr.colours.BU, 0.75)) |
