Finding codes

Every code Fransys can emit. Each row gives the code, severity, stage, meaning and fix.

Code Severity Stage Meaning Fix
ASPECT_CROSS_PARENT ERROR validators An aspect node's parent belongs to a different aspect (function, location or product). Move the node under a parent of the same aspect, or fix the authored parent link.
ASPECT_CYCLE ERROR validators An aspect node's parent chain loops back on itself. Break the cycle by correcting the parent authored on one of the looping nodes.
BASELINE_DIFFERS ERROR release, verify A unit instance in the released subtree, or checked by verify, has a listing that differs from its released baseline. Release the nested unit's new revision, then the containing unit again; or find why its content changed.
BOUNDARY_KIND ERROR validators A unit's boundary function is not a terminal or a connector. Declare the boundary on a terminal or connector function instead.
BOUNDARY_NOT_IN_UNIT ERROR validators A unit's boundary function belongs to an item outside that unit's subtree. Move the boundary declaration to a function whose item is inside the unit, or fix the item's unit/parent.
BOUNDARY_UNCONNECTED ERROR validators A unit's boundary function is not connected across the unit and is not declared unused. Wire the boundary, or leave it open: unused= on d.add for one instance, on d.device for all. A standalone (top-level) unit never fires it, nor does an interface it passes up from a nested unit.
CABLE_CORE_COUNT WARNING or ERROR validators A cable item's core count differs from its product's core-colour count (WARNING when fewer, ERROR when more). Model the missing cores, or correct the product's core_colours list.
CHAIN_BROKEN WARNING render A connection between two "pole" cells was severed into a marker pair though its net has only those two ports. Move the two cells onto one page, or accept the marker pair.
CONDUCTOR_ON_UNINSTALLED WARNING validators A conductor lands on an item that is not marked installed. Mark the item installed, or remove the conductor if the item is absent.
CONNECTION_DRAWN_TWICE ERROR render A connection (or net-group edge) is drawn by more than one route, or drawn together with a cut decision that contradicts it. Remove the duplicate so the connection is drawn or cut once.
CONNECTION_NOT_DRAWN ERROR render A conductor or net-group edge is neither routed on a shared page nor cut with a link marker. Give both ends a location so layout can route or cut them. Check layout.route, layout.symbol_placement and layout.page.
CONNECTION_TO_UNDRAWN WARNING render A connection, net group or rail has an end whose function layout never draws. Draw the missing end's function, or accept it as intentionally undrawn (e.g. board-internal wiring).
CONNECTOR_WIRED_WITHOUT_MATE WARNING validators A conductor from outside a nested unit lands directly on that unit's boundary connector, whose part gender is male or female (neutral or unstated passes). Mate a plug to the boundary connector (u.mate(plug, connector)) and wire the plug's pin instead.
CONTAINMENT_CYCLE ERROR validators An item's physical-containment parent chain loops back on itself. Break the cycle by correcting the parent authored on one of the looping items.
COVER_OVERFLOW WARNING pdf A document's cover text plus revision-history table are estimated taller than the content box and may overlap. Shorten the cover text or the revision entries' text.
DESIGNATION_DUPLICATE ERROR build Two items or unit instances under one parent print one designation: a tag equal to a sibling's text, or a retired or moved released one. Give the item a distinct tag, or none. A tag a released revision reserved needs a new version.
DESIGNATION_MOVED ERROR release An item or unit instance pinned in the previous release now prints a different designation, written or numbered. Restore the released tag; only a new version may change it.
DESIGNATION_NEW_IN_REVISION WARNING build, release A new untagged item or unit instance took the next free number in a later revision. Tag it if the number matters.
DIAGRAM_BOX_OVERLAP ERROR render Two boxes of a block diagram, or a tab and another box, overlap. A layout-engine issue. Report it with the model.
DIAGRAM_CABLE_FANOUT WARNING render A cable reaches three or more boxes, so the block diagram draws one line from its first box to each other box. Usually nothing to fix. Split the cable if a line per pair is not wanted.
DIAGRAM_CABLE_ONE_BOX INFO render A cable's ends reach one box or none, so the block diagram draws no line for it. Usually nothing to fix: the cable runs inside one box, or an end is an unmated plug.
DIAGRAM_LINE_OFF_BOX ERROR render A line of a block diagram does not end on its box's outline or tab. A layout-engine issue. Report it with the model.
DIAGRAM_LINE_THROUGH_BOX ERROR render A line of a block diagram crosses a box other than its own two. A layout-engine issue. Report it with the model.
DIAGRAM_LOOSE_WIRE INFO render In the system reading, a wire with no cable joins two boxes, so the block diagram does not draw it. Usually nothing to fix: the unit pages show it as stubs. Put it in a cable to give it a line.
DIAGRAM_TEXT_OVERLAP ERROR render Two texts of a block diagram overlap. A layout-engine issue. Report it with the model.
DOCUMENT_EMPTY_LIST INFO pdf A document's list page (PLC, terminal, connector, wire-label, designation, cable or BOM) has no rows; the page is left out. Usually nothing to fix (pdf-0019); add records to show it.
DOCUMENT_MIXED_SHEET_FORMATS ERROR pdf A document's pages use more than one sheet format. Give the document (or its unit/layout profile) one consistent sheet format across all its pages.
DOCUMENT_NO_DRAWINGS ERROR pdf A SCHEMATIC, HARNESS_DRAWING or BLOCK_DIAGRAM page has no drawing set, cable or diagram, or its drawing is missing, too large or not drawable yet: interleaved harness cables. Add the missing content, remove the page kind or shorten the texts.
DOCUMENT_NO_TOP_LEVEL_CABLES INFO pdf A SYSTEM document's HARNESS_DRAWING section has nothing to draw: the model has no top-level cable. Usually nothing to fix: add a top-level cable if one was expected.
DOCUMENT_UNIT_UNRESOLVED ERROR validators A document's unit_name matches no unit, or more than one. Make the unit name unique so unit_name resolves to one unit instance.
DRAWING_SET_REPLICA_ONLY INFO pdf A document's drawing set holds only black-box replicas of another unit's boundary. Usually nothing to fix; add content if a page is intended.
EXPORT_NAME_CLASH ERROR build Two different subjects (documents, items) would write to the same file name in out_dir. Give the colliding units, items or documents distinct names (or locations/fragments); two unit instances of one release name need one document per release.
FILE_UNREADABLE ERROR library load A part-file could not be read (missing file, permission error, or bad encoding). Fix the path, permissions or encoding so it reads as UTF-8.
FLOAT_FORBIDDEN ERROR library load A part-file has a bare TOML float value, which the contract forbids (values must be quoted strings). Quote the numeric value as a string in the TOML file.
FUNCTION_UNPLACED_IN_COLUMN INFO render A function is in no authored chain, so layout placed it alone in a column of its own. Usually nothing to fix: add a chain hint only if the function should sit in series with others.
GNYE_NOT_PE ERROR validators A green-yellow conductor is on a net that is not PE. Silent on a net no declared net lists. Recolour it, or connect it to the PE net.
GROUP_SPLIT WARNING render A group of columns is wider than one page, so layout split it across pages between columns. Usually nothing to fix; split a large group into smaller ones for single-page groups.
HARNESS_END_AMBIGUOUS ERROR build Two or more ends of one cable print the same text in its drawing. Place the colliding unit instances at distinct locations, or tag the strips apart.
HARNESS_HOLDS_PLC_MODULE ERROR validators A PLC module sits under an item made with d.harness. Build the rack with d.rack, so its modules print flat.
HARNESS_WITHOUT_TAG ERROR validators A harness (marked, or with a cable child) has no tag or assigned designation, so it has no label. Give it a tag: d.harness(tag=...), or tag= on the item.
INTERFACE_NOT_BUMPED ERROR release The previous released revision of this unit (the highest below this one) has the same interface string but a different boundary section. Bump the interface string if the boundary changed, or restore the previous boundary.
ITEM_PART_MISMATCH ERROR validators An item's functions or ports do not match its part's templates (missing, extra, duplicated, or differing in name, kind, role or marking). Fix the item's authored functions and ports (or the part's templates) so they agree.
ITEM_WITHOUT_PART INFO validators An item has no part, so its functions are authored directly rather than checked against a part's templates. Usually nothing to fix: assign a part to check against templates.
JOIN_UNALIGNED WARNING render A run of same-net, same-facing ports at one end of neighbouring columns could not be aligned onto one row, so layout drew references. Rearrange the columns, or accept the references: the wires still connect through them.
KEEP_TOGETHER_UNMET WARNING render An authored keep_together set could not be kept on one page (it does not fit, its groups sit on different drawing sets, or break_before is invalid). Shrink the set, move its groups onto one drawing set, or drop the hint.
LABEL_UNPLACED WARNING render A tag, marking or cross-reference found no free spot and sits at its default location. Usually nothing to fix; if it looks wrong, rearrange the crowded symbols or wires.
LAYOUT_MISSING ERROR render The model has functions to draw, but layout made no page for them. Add a document so layout runs, and check that the drawn location or unit has connected content.
LIBRARY_VERSION_MISMATCH WARNING render A placement was laid out against a symbol library version different from the one now installed. Re-run layout (build) with the installed electrical_symbols version.
LINE_ON_OUTLINE WARNING render A harness line runs along a unit outline's edge, so the two read as one stroke. A layout-engine issue. Report it with the model.
LINK_FANOUT WARNING render More than one severed link crosses between the same two pages on one physical net. Use a terminal to join the net once instead of severing it more than once between the same two pages.
LINK_PARTNER_UNLOCATED WARNING render A signal crosses into a drawing set with no authored location, so its cross-reference marker has no located prefix. Name the drawing set's unit or location.
LOAD_ABOVE_LIMIT ERROR validators A load's stated draw is above the limit that bounds it. Lower the draw or raise the limit.
LOADS_ABOVE_LIMIT WARNING validators The loads one limit bounds sum above it; none is above it alone. If they run together, raise the limit or split the loads.
LONE_CELL WARNING render A placed symbol has no drawn conductor, or stands alone on a page though its column has more cells elsewhere. Wire the port, or move the column's cells onto one page. A unit's own open boundary functions never give it (decision layout-0077).
MARKDOWN_UNSUPPORTED ERROR pdf A document's cover or notes text uses a Markdown construct the PDF renderer does not support. Rewrite that part of the cover/notes using only the supported Markdown subset.
MARKER_UNPAIRED ERROR render A severed connection's owner or user marker is missing, or a marker on the page matches no severed decision. Usually a layout-engine issue: report it, or check that the cut decision and its two markers agree.
MATE_NOT_CONNECTOR ERROR validators A mate end is not a connector or terminal (a relay coil, say). Mate a connector or terminal.
MATE_PORT_MISMATCH WARNING validators A mate's two functions have different port names, so some ports have no counterpart. Example: a lettered inlet (L1, L2, L3, N, PE) mated to a numbered plug. Rename the ports to match.
MULTILINE_STRING ERROR library load A part-file string value contains a line break, which the TOML contract forbids. Rewrite the value as a single-line string, or use TOML's escaped \n for a newline.
NET_NAME_DUPLICATE ERROR kicad Two or more KiCad netlist nets share one name, so KiCad would merge them into one net on import. Give each net a distinct name.
NET_POTENTIAL_CONFLICT ERROR validators One physical net joins two declared nets that are rails of different supply potentials. Fix the wiring or the net declarations so no physical net joins two potentials.
NET_SHORTED ERROR validators One physical net joins declared nets of different names. Fix the wiring, or give the nets one name if they are one signal (nets of one name join silently).
NET_SINGLE_PIN WARNING kicad A KiCad netlist net has only one pin on it. Usually nothing to fix; otherwise wire its second end.
NET_UNREALISED WARNING validators A declared net's ports fall into more than one physical net, and no single board holds all of them together. Wire the missing conductors, or accept the WARNING if intended.
NODE_WITHOUT_COMPONENT WARNING kicad A netlist pin belongs to an item with no footprint (or is the board's own pin), so KiCad drops it on import. Give the item a footprint, or model the connector as a child item with a footprint.
ORDER_HINT_UNMET WARNING render An authored order hint names two groups that are not on the same drawing set, so no page order can honour it. Move both groups onto the same drawing set, or drop the hint.
OUT_OF_CONTENT_BOX WARNING render A symbol's keep-out box, a label, a marker box, or a route vertex sits outside the page's content box. Rearrange the layout (via authored hints) to fit the content box.
PAD_ON_MULTIPLE_NETS ERROR kicad One component pad appears in more than one net in the KiCad netlist. Fix the wiring so each pad is on exactly one net.
PAGE_OVERFULL WARNING render A page's placed rows are taller than the content box; nothing is scaled to fit. Split the content across more pages, or shrink the authored grouping.
PART_LIBRARY_VERSION_CONFLICT ERROR library load Two PartLibrary records share a name but declare different versions. Make sure only one version of each named part library is loaded.
PART_WITHOUT_FOOTPRINT WARNING kicad A board item's part has no footprint, so the KiCad netlist omits it. Add a footprint to the part, or accept that the item is left out.
PE_NOT_GNYE WARNING validators A single wire on a PE net is not green-yellow (an empty colour is not a finding). Colour the wire GNYE.
PE_PORT_OFF_PE WARNING validators A port with role PE is on a net that is not PE. Silent on a net no declared net lists. Wire the port to the PE net.
PIN_MAP_INCOMPLETE ERROR render A symbol node has no model port bound to any of its symbol ports at all. Add the missing model port or a port_map/symbol choice.
PLACEMENT_DUPLICATE ERROR validators One item is placed more than once in the same aspect (function, location or product). Remove the duplicate placement so the item is placed once per aspect.
PLC_BINDING_SIGNAL_MISMATCH ERROR validators A PLC binding's channel does not have the signal type the request asked for (or is not a declared channel at all). Bind the request to a channel of the matching signal type, or fix the requested signal.
PLC_BINDING_WIRING_MISMATCH ERROR validators A PLC binding disagrees with the wiring: the request or channel function is wired to a different channel or request than its binding. Rebind the request/channel to match the wiring, or rewire it to match the binding.
PLC_REQUEST_UNSERVABLE ERROR build No free PLC channel of the requested signal type on the request's unit chain (its unit declares none, or every one is taken). Add a channel of that signal type to the unit (or a parent unit), or move another request off one.
PORT_DESIGNATION_DUPLICATE ERROR build Two or more ports of one item print the same designation text, so a drawing or list cannot tell them apart. Give the part's pin markings distinct names so each port prints a unique text.
PORT_UNCONNECTED INFO validators A port is in no declared net, on no conductor, and on no mate. Usually nothing to fix unless a connection was intended.
POTENTIAL_IN_TWO_SUPPLIES ERROR validators One potential name is a rail of two differently named supplies. Rename one of the potentials, or merge the two supply declarations if they are the same supply.
POTENTIAL_WITHOUT_SUPPLY WARNING validators A net potential no supply declares: its pins get no rank and no power symbol. Declare the supply with that rail.
POWER_SYMBOL_UNPLACED WARNING render No lead of up to 12 grids kept a power symbol clear of its neighbours, so it keeps one grid and may touch one. Space the pins, or move the device so its power pins have room.
PRODUCT_DESIGNATION_DUPLICATE ERROR build Two items print the same product designation (location plus own label): both at one location or, unplaced, both unnumbered alike in one unit instance. Place one item at a distinct location, or tag it distinctly.
RATING_BREAKING_BELOW_FAULT ERROR validators A protective device breaks less current than the prospective fault at its position. Fit a higher-breaking device.
RATING_BREAKING_NO_DATA WARNING validators A device states breaking points, but none covers the circuit voltage or time constant. Add a point for that voltage or time constant.
RATING_CURRENT_BELOW_BRANCH ERROR validators A function's rated current is below the current its branch can carry. Fit a part rated for the branch's current, or reduce the limit that sets the bound.
RATING_VOLTAGE_BELOW_CIRCUIT ERROR validators A function's rated voltage is below the voltage that stands across it. Fit a part rated for the circuit's voltage, or change the supply or wiring so less stands across it.
REDUNDANT_JOG WARNING render A drawn route leaves a straight line and returns to it where a straight run was free. Usually a layout-engine artifact. Report it if it recurs; otherwise cosmetic.
REFERENCE_BOX_EXCEEDS_ROOM WARNING render A drawing set has 100 or more cross-reference numbers (#n) or pages; a reference box is then wider than layout's room. Check the named pages. Fewer than 100 #n numbers and 100 pages per set avoids it.
REFERENCE_DESIGNATION_DUPLICATE ERROR build Two items in the function or location aspect print the same full reference designation (e.g. two unit instances at one location). Place one of them at a distinct location so the designations differ.
REFERENCE_DUPLICATE ERROR kicad Two parts of the board share one reference designation in the KiCad netlist. Give each part a distinct designation.
RELEASE_FILE_CHANGED ERROR verify A released file's hash differs, the folder holds a file its manifest does not list, or the manifest does not parse. A CRLF-only change in a text file passes. Restore the file from version control; a released revision never changes.
RELEASE_FILE_MISSING ERROR verify A file its manifest lists, or the manifest itself, is gone from a release folder. Restore it from version control.
RELEASE_HISTORY_UNRELEASED ERROR release A history entry after the first released one names a revision with no folder under into, in its own version. Remove the entry, or release that revision first. Older entries are free text.
RELEASE_NESTED_UNRELEASED ERROR release A unit anywhere in the subtree being released (not only direct children) has no baseline folder yet. Release that nested unit first, then release the containing unit.
RELEASE_NO_HISTORY ERROR release The revision being released has no matching Revision history entry. Add the missing entry: history= on @fr.unit, or Design.revision(...) for a system release.
REVISION_ALREADY_RELEASED ERROR release The unit (or system) being released already has a baseline folder whose listing differs from the one to be written. Bump the version or revision, or find why a frozen revision changed.
REVISION_CURRENT_MISSING ERROR validators A unit's (or the project's) current revision has no matching Revision history entry, so a title block prints no date. Add the missing entry: history= on @fr.unit, or Design.revision(rev, date=, text=, created=).
REVISION_DATE_FORMAT ERROR validators A revision entry's date is not in YYYY-MM-DD format. Rewrite the date as YYYY-MM-DD.
REVISION_INITIALS_MISSING ERROR validators A revision entry has no created (author initials). Add the author's initials to the revision entry's created field.
ROUTE_FAILED ERROR render No orthogonal path on the wiring grid could be found between the two ports of a connection. Usual causes: a redundant conductor between two points already on one net (rewire to a point already routed), or crowded geometry around the ports.
ROUTE_SHORTS_NETS ERROR render A drawn route touches a port of another physical net, or two routes of different physical nets touch on the page. Usually a layout-engine issue. Report it; if authored hints crowd the nets, rearrange those hints.
ROUTE_WRONG_PORT ERROR render A route does not run between the two ports it claims to join. Usually a layout-engine bug. Report it.
SHEET_FORMAT_UNUSED WARNING render An authored sheet format is not named by any layout profile, so pages use the house sheet (or the profile's named format). Name the sheet format in the layout profile, or remove it.
SIDE_HINT_NO_HARNESS_LINE WARNING build A d.layout.side hint names an interface that has no harness line, so the hint does nothing. Remove the hint, or connect the interface through a harness line.
STRIP_WITHOUT_TAG ERROR validators A part-less top-level item, usually a floating strip, has no tag and no class code (no terminals, or disagreeing ones). Give it a part, a tag, or terminals of one class code.
SUPPLY_DIFFERS ERROR validators Two declarations of one supply name disagree in current, earthing or rails, or two source declarations in fault current or time constant. Make them agree, or give the differing declarations distinct names.
SYMBOL_DEFAULTED INFO render A function matched no symbol rule or choice, so it was drawn as a plain labelled box. Add a symbol rule or choice for that function's kind or category if a real symbol is wanted.
SYMBOL_OVERLAP WARNING render The keep-out boxes of two symbols on one page overlap. Rearrange the layout (via authored hints).
SYMBOL_PORT_MISSING ERROR render A model port matches no port on its drawn symbol by any of the three binding rules. Fix the part's port names, or add a port_map/symbol choice.
TEXT_CROSSED_BY_ROUTE WARNING render A link marker's stub runs through a text box (a label or another marker's box). Rearrange the crowded labels or markers so the stub has a clear path.
TEXT_OVERLAP WARNING render Two texts on a page overlap, or a text overlaps a symbol body it does not belong to. Rearrange the crowded texts or symbols (via authored hints).
TITLE_BLOCK_NOTICE_OVERFLOW WARNING pdf The project's notice text does not fit the title block's notice cell and would be cut. Shorten the project's notice text.
TITLE_BLOCK_NO_ROOM WARNING pdf The sheet format's title-block band is under the required 20mm. Use a sheet format whose title-block band is tall enough.
TITLE_BLOCK_TEXT_OVERFLOW WARNING pdf A one-line title-block field (title, number, customer, revision, date, author, page title, scope or sheet counter) does not fit its cell and would be cut. Shorten the text, or rely on the shorter fallback label where one applies.
TITLE_BLOCK_UNIT_IDENTITY_MISSING WARNING pdf A unit document's unit has an empty title or number, so that title-block cell will print empty. Give the unit release a title and/or number.
TOML_INVALID ERROR library load A part-file is not valid TOML and could not be parsed. Fix the TOML syntax error the message names.
UNCONNECTED_PIN INFO kicad A pin of a board part is in no net in the KiCad netlist. Usually nothing to fix unless a connection was intended.
UNIT_BOUNDARY_BYPASSED ERROR validators A conductor or mate crosses out of a unit at a function that is not declared that unit's boundary. Declare the function as the unit's boundary, or route it through an existing boundary function.
UNIT_CONNECTOR_DANGLING WARNING validators A terminal or connector function belongs directly to a unit, is not its boundary, and connects to nothing. Wire the function, or remove it if it is not needed.
UNIT_CYCLE ERROR validators A unit's parent chain loops back on itself. Break the cycle by correcting the parent authored on one of the looping units.
UNIT_GROUP_SPLIT WARNING render A unit group is wider than one page, so layout split it across pages; each page keeps an outline for its own interfaces. Even the edges with side hints (d.layout.side), or give the unit fewer harness interfaces.
UNKNOWN_SYMBOL_KEY ERROR render A placement's symbol key is not in the installed symbol library. Fix the symbol key (rule, choice, or part data), or install a library version that has it.
UNUSED_CONTRADICTED WARNING validators A boundary declared unused names a function that is no unit's boundary, or is in fact connected across the unit. Remove the unused= if the function is wired, or fix which unit/function it names.
WIRE_COLOUR_UNKNOWN ERROR validators A wire or cable-product core colour is not a recognized IEC 60757 colour code (or combination). Use a base code, a combination of two, a base code with a core number, or the shield code SH.
WIRE_NOT_ORTHOGONAL WARNING render A drawn route has a segment that is not orthogonal (not purely horizontal or vertical). Usually a layout-engine artifact. Report it if it recurs.
WIRE_ON_TWO_HARNESSES ERROR validators A wire joins plugs of two harnesses. Wire to a plug of one harness, or use a cable.
WIRE_OVER_LABEL WARNING render A drawn route runs through a label's (or link marker's) box. Rearrange the crowded labels/markers (via authored hints) so the route has a clear path.
WIRE_THROUGH_SYMBOL WARNING render A drawn route runs through the keep-out box of a symbol it does not end at. Rearrange the layout (via authored hints) so the route need not cross that symbol.
