Finding codes: validators, build and release

Codes the model checks, the build, release and verify and the library load emit. Who acts is explained in findings.md.

Code Severity Stage Who acts Meaning Fix
ASPECT_CROSS_PARENT ERROR validators consumer An aspect node's parent belongs to a different aspect (function, location or product). Move the node under a parent of the same aspect, or fix its authored parent.
ASPECT_CYCLE ERROR validators consumer An aspect node's parent chain loops back on itself. Correct the parent authored on one of the looping nodes.
BAR_NOT_PE ERROR validators consumer A port of a bar function has a role other than pe. A bar carries protective earth only, until the copper bar drawing (owner question) is ruled. Set role = "pe" on the port in the part file.
BASELINE_DIFFERS ERROR release, verify consumer A unit instance in the released subtree, or checked by verify, has a listing differing from its released baseline. Release the nested unit's new revision, then the containing unit again, or find why its content changed.
BOUNDARY_NOT_IN_UNIT ERROR validators consumer A unit's boundary function belongs to an item outside that unit's subtree. Declare the boundary on a function whose item is in the unit, or fix the item's unit/parent.
BOUNDARY_UNCONNECTED ERROR validators consumer A unit's boundary function is not connected across the unit nor declared unused. Wire the boundary, or leave it open: unused= on d.add for one instance, on d.device for all. A unit alone in its design never fires it, nor an interface passed up from a nested unit.
CABLE_CORE_COUNT WARNING or ERROR validators consumer A cable item's core count differs from its product's core-colour count (WARNING when fewer, ERROR when more). Wire the missing cores, mark a core you leave unused with w.spare(colour) (or w.spare() for all the rest), or correct the product's core_colours list. A spare or one-ended screen counts as a core.
CONDUCTOR_ON_UNINSTALLED WARNING validators consumer A conductor lands on an item that is not marked installed. Mark the item installed, or remove the conductor if it is absent.
CONNECTOR_WIRED_WITHOUT_MATE WARNING validators consumer A conductor from outside a nested unit lands directly on its boundary connector, whose part gender is male or female (neutral or unstated passes). Mate a plug to the boundary connector (u.mate(plug, connector)) and wire the plug's pin instead.
CONTAINMENT_CYCLE ERROR validators consumer An item's physical-containment parent chain loops back on itself. Correct the parent authored on one of the looping items.
CORE_INDEX_PAST_PRODUCT ERROR validators consumer A cable core is numbered past the core count of the cable's product. Use a core from 1 to the product's core count, or choose a part with more cores.
DESIGNATION_DUPLICATE ERROR build consumer Two items or unit instances under one parent print one designation: a tag equal to a sibling's text, or a retired or moved released one. Give the item a distinct tag, or none. A tag a released revision reserved needs a new version.
DESIGNATION_MOVED ERROR release consumer An item or unit instance pinned in the previous release now prints a different designation, written or numbered. Restore the released tag; only a new version may change it.
DESIGNATION_NEW_IN_REVISION INFO build, release note A new untagged item or unit instance took the next free number in a later revision. Nothing is wrong; tag it if its number must stay fixed.
DOCUMENT_UNIT_UNRESOLVED ERROR validators consumer A document's unit_name matches no unit, or more than one. Make the unit name unique so unit_name resolves to one instance.
EXPORT_NAME_CLASH ERROR build consumer Two different subjects (documents, items) would write to the same file name in out_dir. Give the colliding units, items or documents distinct names (or locations/fragments); two instances of one release name need one document per release.
FILE_UNREADABLE ERROR library load consumer A part-file could not be read (missing file, permission error, or bad encoding). Fix the path, permissions or encoding (UTF-8).
FLOAT_FORBIDDEN ERROR library load consumer A part-file has a bare TOML float, which the contract forbids (quote values as strings). Quote the numeric value as a string.
FUNCTION_HALF_CONNECTED WARNING validators consumer A two-port coil, load, contact, switch, protection or actuator is connected at one port and open at the other. Wire the open port, or remove the half-wired function.
GNYE_NOT_PE ERROR or WARNING validators consumer A green-yellow conductor is on a net that is not PE: an ERROR on a net a declared net lists, a WARNING on a net none lists (IEC 60445 keeps green-yellow for PE). Recolour it, or connect it to the PE net and declare it with d.earth.
HARNESS_END_AMBIGUOUS ERROR build consumer Two or more ends of one cable print the same text in its drawing. Place the colliding unit instances at distinct locations, or tag the strips apart.
HARNESS_HOLDS_PLC_MODULE ERROR validators consumer A PLC module sits under an item made with d.harness. Build the rack with d.rack, so its modules print flat.
HARNESS_WITHOUT_TAG ERROR validators consumer A harness (marked, or with a cable child) has no tag or assigned designation, so it has no label. Give it a tag: d.harness(tag=...), or tag= on the item.
INTERFACE_NOT_BUMPED ERROR release consumer The previous released revision of this unit (the highest below this one) has the same interface string but a different boundary. Bump the interface string if the boundary changed, or restore the previous boundary.
ITEM_PART_MISMATCH ERROR validators consumer An item's functions or ports do not match its part's templates (missing, extra, duplicated, or differing in name, kind, role or marking). Fix the item's authored functions and ports (or the part's templates) so they agree.
ITEM_WITHOUT_PART INFO validators note A non-external item has no part, so its functions are authored directly, not checked against templates. Usually nothing to fix: assign a part to check against templates.
LOADS_ABOVE_LIMIT WARNING validators consumer The loads one limit bounds sum above it; none is above it alone. If they run together, raise the limit or split the loads.
LOAD_ABOVE_LIMIT ERROR validators consumer A load's stated draw is above the limit that bounds it. Lower the draw or raise the limit.
MATE_NOT_CONNECTOR ERROR validators consumer A mate end is not a connector or terminal (a relay coil, say). Mate a connector or terminal.
MATE_PORT_MISMATCH WARNING validators consumer A mate's two functions have different port names, so some ports have no counterpart. Example: a lettered inlet (L1, L2, L3, N, PE) mated to a numbered plug. Rename the ports to match.
MULTILINE_STRING ERROR library load consumer A part-file string contains a line break, which the contract forbids. Use a single-line string, or TOML's escaped \n.
NET_POTENTIAL_CONFLICT ERROR validators consumer One physical net joins two declared nets that are rails of different supply potentials. Fix the wiring or net declarations so no net joins two potentials.
NET_SHORTED ERROR validators consumer One physical net joins declared nets of different names. Fix the wiring, or give the nets one name if they are one signal (same-name nets join silently).
NET_UNREALISED WARNING validators consumer A declared net's ports fall into more than one physical net, and no single board holds them all. Not for the PE net. Wire the missing conductors, or remove the ports that should not share the declared net.
PART_LIBRARY_VERSION_CONFLICT ERROR library load consumer Two PartLibrary records share a name but declare different versions. Load only one version of each named part library.
PE_NOT_GNYE WARNING validators consumer A single wire on a PE net is not green-yellow (an empty colour is not a finding). Colour the wire GNYE.
PE_PORT_OFF_PE WARNING validators consumer A port with role PE is on a net that is not PE. Wire the port to the PE net.
PLACEMENT_DUPLICATE ERROR validators consumer One item is placed more than once in the same aspect (function, location or product). Remove the duplicate placement so the item is placed once per aspect.
PLC_BINDING_SIGNAL_MISMATCH ERROR validators consumer A PLC binding's channel does not have the signal type the request asked for (or is not a declared channel at all). The message names the asked kind, the channel, its kind and both fixes. Rewire the request to a channel of the asked kind, or ask for the channel's kind.
PLC_BINDING_WIRING_MISMATCH ERROR validators consumer A PLC binding disagrees with the wiring: the request or channel function is wired to a different channel or request than its binding. Rebind the request/channel to match the wiring, or rewire it to match the binding.
PLC_CHANNEL_CONTESTED ERROR build consumer Two or more PLC requests of the channel's signal are wired to the same channel. The finding names the channel's pins and every request; none of them binds, and none goes to the free queue. One channel reads one signal: keep one request, or wire each request to its own channel.
PLC_REQUEST_AMBIGUOUS ERROR build consumer A PLC request is wired so that several free channels of its signal tie: its net reaches them all, or all by a direct conductor. It gets no binding. Wire the request to one channel directly, or free the other channels.
PLC_REQUEST_UNSERVABLE ERROR build consumer No free PLC channel of the requested signal type on the request's unit chain (its unit declares none, or every one is taken). Add a channel of that signal type to the unit (or a parent unit), or move another request off one.
PORT_DESIGNATION_DUPLICATE ERROR build consumer Two or more ports of one item print the same designation text, so a drawing or list cannot tell them apart. Give the part's pin markings distinct names so each port prints a unique text.
POTENTIAL_IN_TWO_SUPPLIES ERROR validators consumer One potential name is a rail of two differently named supplies. Rename one of the potentials, or merge the two supply declarations if they are the same supply.
POTENTIAL_WITHOUT_SUPPLY WARNING validators consumer A net potential no supply declares: its pins get no rank and no power symbol. Declare the supply with that rail.
PRODUCT_DESIGNATION_DUPLICATE ERROR build consumer Two items print the same product designation (location plus own label): both at one location or, unplaced, both unnumbered alike in one unit instance. Place one item at a distinct location, or tag it.
RATING_BREAKING_BELOW_FAULT ERROR validators consumer A protective device breaks less current than the prospective fault at its position. Fit a higher-breaking device.
RATING_BREAKING_NO_DATA WARNING validators consumer A device states breaking points, but none covers the circuit voltage or time constant. Add a point for that voltage or time constant.
RATING_CURRENT_BELOW_BRANCH ERROR validators consumer A function's rated current is below the current its branch can carry. Fit a part rated for the branch's current, or reduce the limit that sets the bound.
RATING_CURRENT_KIND_UNSTATED WARNING validators consumer A function's part states a voltage rating for AC or for DC only, and the function stands on rails of the other current kind. State the missing voltage rating in the part, or use a part rated for that kind.
RATING_VOLTAGE_BELOW_CIRCUIT ERROR validators consumer A function's rated voltage is below the voltage that stands across it. Fit a part rated for the circuit's voltage, or change the supply or wiring to lower it.
REFERENCE_DESIGNATION_DUPLICATE ERROR build consumer Two items in the function or location aspect print the same full reference designation (e.g. two unit instances at one location). Place one of them at a distinct location so the designations differ.
RELEASE_FILE_CHANGED ERROR verify consumer A released file's hash differs, the folder holds a file its manifest omits, or the manifest does not parse. A CRLF-only change in a text file passes. Restore the file from version control; a released revision never changes.
RELEASE_FILE_MISSING ERROR verify consumer A file its manifest lists, or the manifest itself, is gone from a release folder. Restore it from version control.
RELEASE_HISTORY_UNRELEASED ERROR release consumer A history entry after the first released one names a revision with no folder under into, in its own version. Remove the entry, or release that revision first. Older entries are free text.
RELEASE_NESTED_UNRELEASED ERROR release consumer A unit anywhere in the subtree being released (not only direct children) has no baseline folder yet. Release that nested unit first, then release the containing unit.
RELEASE_NO_HISTORY ERROR release consumer The revision being released has no matching Revision history entry. Add the missing entry: history= on @fr.unit, or Design.revision(...) for a system release.
REVISION_ALREADY_RELEASED ERROR release consumer The unit (or system) being released already has a baseline folder whose listing differs from the one to be written. Bump the version or revision, or find why a frozen revision changed.
REVISION_CURRENT_MISSING ERROR validators consumer A unit's (or the project's) current revision has no matching Revision history entry, so a title block prints no date. Add the missing entry: history= on @fr.unit, or Design.revision(rev, date=, text=, created=).
REVISION_DATE_FORMAT ERROR validators consumer A revision entry's date is not in YYYY-MM-DD format. Rewrite the date as YYYY-MM-DD.
REVISION_INITIALS_MISSING ERROR validators consumer A revision entry has no created (author initials). Add the author's initials to the revision entry's created field.
SIDE_HINT_NO_HARNESS_LINE WARNING build consumer A d.layout.side hint names an interface that has no harness line, so the hint does nothing. Remove the hint, or connect the interface through a harness line.
STRIP_WITHOUT_TAG ERROR validators consumer A part-less top-level item, usually a floating strip, has no tag and no class code (no terminals, or disagreeing ones). Give it a part, a tag, or terminals of one class code.
SUPPLY_DIFFERS ERROR validators consumer Two declarations of one supply name disagree in current, earthing or rails, or two source declarations in fault current or time constant. Make them agree, or give the differing declarations distinct names.
TOML_INVALID ERROR library load consumer A part-file is not valid TOML. Fix the TOML syntax error named.
UNIT_BOUNDARY_BYPASSED ERROR validators consumer A conductor or mate crosses out of a unit at a function that is not declared that unit's boundary. Declare it the unit's boundary, or route it through an existing boundary function.
UNIT_CYCLE ERROR validators consumer A unit's parent chain loops back on itself. Correct the parent authored on one of the looping units.
UNUSED_CONTRADICTED WARNING validators consumer A boundary declared unused names a function that is no unit's boundary, or is connected across the unit the declaration is on. Remove unused= if the function is wired, or fix the unit/function it names.
WIRE_COLOUR_UNKNOWN ERROR validators consumer A wire or cable-product core colour is not a recognized IEC 60757 colour code (or combination). Use a base code, a combination of two, a base code with a core number, or shield code SH.
WIRE_ON_TWO_HARNESSES ERROR validators consumer A wire joins plugs of two harnesses. Wire to a plug of one harness, or use a cable.
WIRE_ROW_UNRESOLVED ERROR build consumer A series or detail wire was written without a row, and at build end its net carries no rail of its unit, states no source_row and holds no PLC channel signal, or carries rails of two rows. The message names the net and the wire's two pins. Give wire= on that series: a (colour, size), or a size with a row table. A rail never reaches a wire across a unit boundary from its container.
