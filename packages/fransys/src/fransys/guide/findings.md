# Finding codes

Every code Fransys can emit. Each row gives the code, severity, stage, meaning and fix.

| Code | Severity | Stage | Meaning | Fix |
| --- | --- | --- | --- | --- |
| ASPECT_CROSS_PARENT | ERROR | validators | An aspect node's parent belongs to a different aspect (function, location or product) than the node itself. | Move the node under a parent of the same aspect, or fix the authored parent link. |
| ASPECT_CYCLE | ERROR | validators | An aspect node's parent chain loops back on itself. | Break the cycle by correcting the parent authored on one of the looping nodes. |
| BASELINE_DIFFERS | ERROR | release, verify | A unit instance (in the released subtree, or checked by `verify`) has a listing that no longer matches its released baseline. | Release that nested unit's own new revision first (bumping it), then release the containing unit again; or find why its content changed. |
| BOUNDARY_KIND | ERROR | validators | A unit's declared boundary function is not a terminal or a connector, so it cannot carry a real connection across the unit. | Declare the boundary on a terminal or connector function instead. |
| BOUNDARY_NOT_IN_UNIT | ERROR | validators | A unit's declared boundary function's item does not belong to that unit's own subtree. | Move the boundary declaration to a function whose item is inside the unit, or fix the item's unit/parent. |
| BOUNDARY_UNCONNECTED | ERROR | validators | A unit's boundary function is not connected across the unit and is not declared unused. | Wire the boundary, or leave it open: `unused=` on `d.add` for one instance, `unused=` on `d.device` for all. It never fires for a standalone (top-level) unit, whose outside is open. |
| CABLE_CORE_COUNT | WARNING or ERROR | validators | A cable item's number of core conductors differs from the core-colour count its product declares (WARNING when fewer, ERROR when more). | Model the missing cores, or correct the product's `core_colours` list. |
| CHAIN_BROKEN | WARNING | render | A drawn connection between two "pole" cells was severed into a marker pair even though its physical net has only those two ports, so the pair could have stayed one drawn link. | Move the two cells onto the same page, or accept the marker pair if the page layout requires the split. |
| CONDUCTOR_ON_UNINSTALLED | WARNING | validators | A conductor lands on an item that is not marked installed. | Mark the item installed, or remove/relocate the conductor if the item is genuinely absent from this build. |
| CONNECTION_DRAWN_TWICE | ERROR | render | A connection (or net-group edge) is drawn by more than one route, or drawn together with a cut decision that contradicts it. | Remove the duplicate route or decision so the connection is drawn (or cut) exactly once. |
| CONNECTION_NOT_DRAWN | ERROR | render | A conductor or net-group edge is neither routed on a shared page nor cut with a link-marker decision, so the drawing does not show it. | Give both ends a location so layout can route or cut them; often one end has none. Check `layout.route`, `layout.symbol_placement` and `layout.page` to see where the ends landed. |
| CONNECTION_TO_UNDRAWN | WARNING | render | A connection, net group or rail has an end that layout never draws (its function is excluded), so that end is silently dropped. | Draw the missing end's function, or accept that this end is intentionally undrawn (e.g. board-internal wiring). |
| CONNECTOR_WIRED_WITHOUT_MATE | WARNING | validators | A conductor from outside a nested unit lands directly on that unit's boundary connector, whose part gender is male or female. A neutral or unstated gender passes silently. | Mate a plug to the boundary connector (`u.mate(plug, connector)`) and wire the plug's pin instead. |
| CONTAINMENT_CYCLE | ERROR | validators | An item's physical-containment parent chain loops back on itself. | Break the cycle by correcting the parent authored on one of the looping items. |
| COVER_OVERFLOW | WARNING | pdf | A document's cover text plus its revision-history table are estimated to be taller than the content box, so they may overlap on the printed page. | Shorten the cover text or the revision entries' descriptions so both fit the page. |
| DESIGNATION_DUPLICATE | ERROR | build | Two items or unit instances under one parent print one designation: a tag equal to a sibling's text, or a retired or moved released one. | Give the item a distinct tag, or none. A tag a released revision reserved needs a new version. |
| DESIGNATION_MOVED | ERROR | release | An item or unit instance pinned in the previous release now prints a different designation, written or numbered. | Restore the released tag; only a new version may change it. |
| DESIGNATION_NEW_IN_REVISION | WARNING | build, release | A new untagged item or unit instance took the next free number in a later revision. | Tag it if the number matters. |
| DOCUMENT_EMPTY_LIST | INFO | pdf | A document's list page (PLC, terminal, connector, wire-label, designation, cable or BOM) has no rows; the page is left out. | Usually nothing to fix: the page is left out (pdf-0019); add records to show it. |
| DOCUMENT_MIXED_SHEET_FORMATS | ERROR | pdf | A document's pages use more than one sheet format. | Give the document (or its unit/layout profile) one consistent sheet format across all its pages. |
| DOCUMENT_NO_DRAWINGS | ERROR | pdf | A document declares a SCHEMATIC or HARNESS_DRAWING page, but the model has no matching drawing set or cable, or the drawing for one is missing. | Add the missing drawing set, cable, or unit content the document expects, or remove the page kind if nothing should be drawn there. |
| DOCUMENT_NO_TOP_LEVEL_CABLES | INFO | pdf | A SYSTEM document's HARNESS_DRAWING section has nothing to draw because the model has no top-level cable at all. | Usually nothing to fix: add a top-level cable if one was expected, otherwise this is just a reminder that the section is empty. |
| DOCUMENT_UNIT_UNRESOLVED | ERROR | validators | A document's `unit_name` matches zero units, or more than one, in the model. | Rename the unit release, or make the unit name unique, so the document's `unit_name` resolves to exactly one unit instance. |
| DRAWING_SET_REPLICA_ONLY | INFO | pdf | A document's drawing set holds only black-box replicas of another unit's boundary, so nothing of its own is drawn there. | Usually nothing to fix: it explains why an expected drawing set produced no page; add real content there only if some was actually intended. |
| EXPORT_NAME_CLASH | ERROR | build | Two different subjects (documents, items) would write to the same file name in `out_dir`. | Give the colliding units/items/documents distinct names (or locations/fragments) so their exports land on different file names; when two unit instances share one release name, keep one document per release. |
| FILE_UNREADABLE | ERROR | library load | A part-file could not be read from disk (missing file, permission error, or bad encoding). | Fix the file's path, permissions, or encoding so it can be read as UTF-8 text. |
| FLOAT_FORBIDDEN | ERROR | library load | A part-file has a bare TOML float value, which the contract forbids (values must be quoted strings). | Quote the numeric value as a string in the TOML file. |
| FUNCTION_UNPLACED_IN_COLUMN | INFO | render | A function is in no authored chain, so layout placed it alone in a column of its own. | Usually nothing to fix: add a chain hint only if the function was meant to be placed in series with others. |
| GNYE_NOT_PE | ERROR | validators | A green-yellow conductor is on a net that is not PE. Silent on a net no declared net lists. | Recolour it, or connect it to the PE net. |
| GROUP_SPLIT | WARNING | render | A group of columns is wider than one page, so layout split it across pages between columns. | Usually nothing to fix; split a large group into smaller ones for single-page groups. |
| HARNESS_END_AMBIGUOUS | ERROR | build | Two or more ends of one cable print the same text in its drawing, so the reader cannot tell them apart. | Place the colliding unit instances at distinct locations, or tag the strips apart, so each end of the cable prints a unique text. |
| HARNESS_WITHOUT_TAG | ERROR | validators | An item with a cable child reads as a harness, but has no tag or assigned designation of its own, so it has no label to print. | Give it a tag: `d.harness(tag=...)`, or `tag=` on the item. |
| INTERFACE_NOT_BUMPED | ERROR | release | The previous released revision of this unit (the highest below the one being released) has the same interface string but a different boundary section. | Bump the interface string if the boundary changed, or restore the previous boundary. |
| ITEM_PART_MISMATCH | ERROR | validators | An item's functions or ports do not exactly match what its part's templates declare (missing, extra, duplicated, or differing in name/kind/role/marking). | Fix the item's authored functions/ports (or the part's templates) so they agree exactly. |
| ITEM_WITHOUT_PART | INFO | validators | An item has no `part`, so its functions are authored directly rather than checked against a part's templates. | Usually nothing to fix: assign a `part` only if the item should be checked against a part's own templates. |
| JOIN_UNALIGNED | WARNING | render | A run of same-net, same-facing ports at one end of neighbouring columns could not be aligned onto one row, so layout drew ordinary references there instead of a horizontal join. | Rearrange the columns, or accept the references: the wires still connect through them. |
| KEEP_TOGETHER_UNMET | WARNING | render | An authored `keep_together` set of groups could not be kept on one page (it does not fit, its groups are on different drawing sets, or its `break_before` is invalid). | Shrink the set, move its groups onto one drawing set, or drop the hint if the groups cannot share a page. |
| LABEL_UNPLACED | WARNING | render | A tag, marking or cross-reference found no free spot and was placed at its default location anyway, possibly overlapping something. | Usually nothing to fix: if it looks wrong on the page, rearrange the crowded symbols or wires so there is room for the label. |
| LAYOUT_MISSING | ERROR | render | The model has functions that should be drawn, but no page was laid out for any of them. | Add a document so layout runs, and check that the drawn location or unit actually has connected content. |
| LIBRARY_VERSION_MISMATCH | WARNING | render | A placement was laid out against a symbol library version different from the one now installed. | Re-run layout (build) with the currently installed `electrical_symbols` version so placements match it. |
| LINK_FANOUT | WARNING | render | More than one severed link crosses between the same two pages on one physical net. | Use a terminal to join the net once instead of severing it more than once between the same two pages. |
| LINK_PARTNER_UNLOCATED | WARNING | render | A signal crosses into a drawing set that has no location authored, so its cross-reference marker cannot print a located prefix. | Give the drawing set's unit or location a name so the marker can print a proper cross-reference. |
| LONE_CELL | WARNING | render | A placed symbol has no drawn conductor at all, or stands alone on a page although its column has more cells elsewhere. | Wire the port, or move the column's cells onto one page. A unit's own open boundary functions never give it (decision layout-0077). |
| MARKDOWN_UNSUPPORTED | ERROR | pdf | A document's cover or notes text uses a Markdown construct the PDF renderer does not support. | Rewrite that part of the cover/notes using only the supported Markdown subset. |
| MARKER_UNPAIRED | ERROR | render | A severed connection's owner or user marker is missing, or a marker on the page matches no severed decision. | Usually a layout-engine issue rather than an authoring fix. Report it; otherwise check that the connection's cut decision and its two markers agree. |
| MATE_PORT_MISMATCH | WARNING | validators | The two functions of a mate do not have matching port names, so some ports on one side have no counterpart on the other. | For example a lettered inlet (L1, L2, L3, N, PE) mated to a numbered plug. Rename the ports to match; if the mismatch is expected, a test must read this WARNING. |
| MULTILINE_STRING | ERROR | library load | A part-file string value contains a line break, which the TOML contract forbids. | Rewrite the value as a single-line string (or use TOML's escaped `\n` if a literal newline is truly needed). |
| NET_NAME_DUPLICATE | ERROR | kicad | Two or more KiCad netlist nets share one name, so KiCad would merge them into one net on import. | Give each net a distinct name. |
| NET_POTENTIAL_CONFLICT | ERROR | validators | One physical net joins two declared nets that are rails of different supply potentials. | Fix the wiring or the net declarations so no physical net shorts two different potentials together. |
| NET_SHORTED | ERROR | validators | One physical net (through the actual conductors) joins more than one declared net. | Fix the wiring so each physical net corresponds to exactly one declared net, or merge the declared nets if they really are the same. |
| NET_SINGLE_PIN | WARNING | kicad | A KiCad netlist net has only one pin on it. | Usually nothing to fix if that pin is genuinely unconnected on purpose; otherwise wire the missing second end. |
| NET_UNREALISED | WARNING | validators | A declared net's ports fall into more than one physical net, and no single board holds all of them together. | Wire the missing conductors so the declared net is physically realized, or accept the WARNING if the design is deliberately incomplete so far. |
| NODE_WITHOUT_COMPONENT | WARNING | kicad | A netlist pin belongs to an item with no footprint (or is the board's own pin), so it has no KiCad component and KiCad drops it on import. | Give the item a footprint, or model the connector as a child item with a footprint instead of a bare function of the board. |
| ORDER_HINT_UNMET | WARNING | render | An authored order hint names two groups that are not on the same drawing set, so no page order can honour it. | Move both groups onto the same drawing set, or drop the hint. |
| OUT_OF_CONTENT_BOX | WARNING | render | A symbol's keep-out box, a label, a marker box, or a route vertex sits outside the page's content box. | Rearrange the layout (via authored hints) so everything fits within the content box; reducing crowding upstream usually resolves it. |
| PAD_ON_MULTIPLE_NETS | ERROR | kicad | One component pad appears in more than one net in the KiCad netlist. | Fix the wiring so each pad is on exactly one net. |
| PAGE_OVERFULL | WARNING | render | A page's placed rows are taller than the content box; nothing is scaled to fit. | Split the content across more pages, or shrink the authored grouping. |
| PART_LIBRARY_VERSION_CONFLICT | ERROR | library load | Two `PartLibrary` records share a name but declare different versions. | Make sure only one version of each named part library is loaded. |
| PART_WITHOUT_FOOTPRINT | WARNING | kicad | A board item's part has no footprint, so the KiCad netlist omits it. | Add a footprint to the part, or accept that this item will not appear in the KiCad netlist. |
| PE_NOT_GNYE | WARNING | validators | A single wire on a PE net is not green-yellow (an empty colour is not a finding). | Colour the wire GNYE. |
| PE_PORT_OFF_PE | WARNING | validators | A port with role PE is on a net that is not PE. Silent on a net no declared net lists. | Wire the port to the PE net. |
| PIN_MAP_INCOMPLETE | ERROR | render | A symbol node has no model port bound to any of its symbol ports at all. | Add the missing model port (or a `port_map`/symbol choice) so every symbol node gets at least one bound port. |
| PLACEMENT_DUPLICATE | ERROR | validators | One item is placed more than once in the same aspect (function, location or product). | Remove the duplicate placement so the item is placed once per aspect. |
| PLC_BINDING_SIGNAL_MISMATCH | ERROR | validators | A PLC binding's channel does not have the signal type the request asked for (or is not a declared channel at all). | Bind the request to a channel of the matching signal type, or fix the requested signal. |
| PLC_BINDING_WIRING_MISMATCH | ERROR | validators | A PLC binding disagrees with what is actually wired: the request or channel function is physically wired to a different channel/request than the one it is bound to. | Rebind the request/channel to match the wiring, or rewire it to match the binding. |
| PLC_REQUEST_UNSERVABLE | ERROR | build | No free PLC channel of the requested signal type was available on the request's unit chain (its own unit declares none, or every matching one is taken). | Add a channel of that signal type to the unit (or a parent unit), or move another request off one. |
| PORT_DESIGNATION_DUPLICATE | ERROR | build | Two or more ports of one item print the same designation text, so a drawing or list cannot tell them apart. | Give the part's pin markings distinct names so each port prints a unique text. |
| PORT_UNCONNECTED | INFO | validators | A port is in no declared net, on no conductor, and on no mate. | Usually nothing to fix: wire the port only if a connection was actually intended there. |
| POTENTIAL_IN_TWO_SUPPLIES | ERROR | validators | One potential name is a rail of two differently named supplies. | Rename one of the potentials, or merge the two supply declarations if they really are the same supply. |
| POTENTIAL_WITHOUT_SUPPLY | WARNING | validators | A net potential no supply declares: its pins get no rank and no power symbol. | Declare the supply with that rail. |
| POWER_SYMBOL_UNPLACED | WARNING | render | No lead of up to 12 grids kept a power symbol clear of its neighbours, so it keeps one grid and may touch one. | Space the pins, or move the device so its power pins have room. |
| PRODUCT_DESIGNATION_DUPLICATE | ERROR | build | Two items print the same product designation (location plus own label), either both placed at the same location or, when unplaced, both unnumbered alike within one unit instance. | Place one of the items at a distinct location, or give it a distinct tag. |
| RATING_CURRENT_BELOW_BRANCH | ERROR | validators | A function's rated current is below the current its branch can actually carry. | Fit a part rated for the branch's actual current, or reduce the source/protective-device limit that sets the branch's bound. |
| RATING_VOLTAGE_BELOW_CIRCUIT | ERROR | validators | A function's rated voltage is below the voltage that actually stands across it. | Fit a part rated for the circuit's actual voltage, or change the supply/wiring so less voltage stands across the function. |
| REDUNDANT_JOG | WARNING | render | A drawn route leaves a straight line and returns to it where a straight run was actually free. | Usually a layout-engine artifact rather than an authoring fix. Report it if it recurs; otherwise cosmetic only. |
| REFERENCE_DESIGNATION_DUPLICATE | ERROR | build | Two items placed in the function or location aspect render the identical full reference designation (e.g. two unit instances placed at one location). | Place one of the unit instances (or items) at a distinct location so their reference designations differ. |
| REFERENCE_DUPLICATE | ERROR | kicad | Two parts of the board share one reference designation in the KiCad netlist. | Give each part a distinct designation. |
| RELEASE_NESTED_UNRELEASED | ERROR | release | A unit anywhere in the subtree being released (not only directly nested units) has no on-disk baseline folder yet. | Release that nested unit first, then release the containing unit. |
| RELEASE_NO_HISTORY | ERROR | release | The revision being released has no matching `Revision` history entry. | Call `Scope.revision(...)` (or the top-level `Design.revision(...)` for a system release) to add the missing entry before releasing. |
| REVISION_ALREADY_RELEASED | ERROR | release | The unit (or the whole system) being released already has a baseline folder on disk whose stored listing differs from the one about to be written. | Bump the version or revision before releasing again, or find out why the content changed if this revision was meant to stay frozen. |
| REVISION_CURRENT_MISSING | ERROR | validators | A unit's (or the project's) current version/revision has no matching `Revision` history entry, so a title block would print no date. | Call `Scope.revision(rev, date=..., text=..., created=...)` to add the missing entry for that version and revision. |
| REVISION_DATE_FORMAT | ERROR | validators | A revision entry's date is not in `YYYY-MM-DD` format. | Rewrite the date as `YYYY-MM-DD`. |
| REVISION_INITIALS_MISSING | ERROR | validators | A revision entry has no `created` (author initials). | Add the author's initials to the revision entry's `created` field. |
| ROUTE_FAILED | ERROR | render | No orthogonal path on the wiring grid could be found between the two ports of a connection. | Usual causes: a redundant conductor between two points already on the same net (rewire to a point already routed on that net), or crowded geometry around the ports. |
| ROUTE_SHORTS_NETS | ERROR | render | A drawn route touches a port of another physical net, or two routes of different physical nets touch on the page. | Usually a layout-engine issue. Report it; if authored hints caused the crowding, rearrange to give the two nets more separation. |
| ROUTE_WRONG_PORT | ERROR | render | A route does not actually run between the two ports it claims to join. | Usually a layout-engine bug rather than an authoring fix. Report it. |
| SHEET_FORMAT_UNUSED | WARNING | render | An authored sheet format is not named by any layout profile, so pages are drawn on the house sheet (or the profile's own named format) instead. | Either name the sheet format in the layout profile, or remove the unused authored sheet format. |
| STRIP_WITHOUT_TAG | ERROR | validators | A part-less top-level item, usually a floating strip, has no tag and no class code (no terminals, or disagreeing ones). | Give it a part, a tag, or terminals of one class code. |
| SUPPLY_DIFFERS | ERROR | validators | Two declarations of one supply name disagree in current, earthing, or rails. | Make every declaration of that supply name agree, or give the differing declarations distinct names. |
| SYMBOL_DEFAULTED | INFO | render | A function matched no symbol rule or choice, so it was drawn as a plain labelled box. | Add a symbol rule or choice for that function's kind/category if a real symbol is wanted instead of a generic box. |
| SYMBOL_OVERLAP | WARNING | render | The keep-out boxes of two symbols on one page overlap. | Rearrange the layout (via authored hints) so the two symbols do not collide. |
| SYMBOL_PORT_MISSING | ERROR | render | A model port has no matching port on the symbol it was drawn with, by any of the three binding rules. | Fix the part's port names, or add a `port_map`/symbol choice, so every model port maps to a real symbol port. |
| TEXT_CROSSED_BY_ROUTE | WARNING | render | A link marker's stub runs through a text box (a label or another marker's box). | Rearrange the crowded labels or markers so the stub has a clear path. |
| TEXT_OVERLAP | WARNING | render | Two texts on a page overlap, or a text overlaps a symbol body it does not belong to. | Rearrange the crowded texts/symbols (via authored hints) so the boxes no longer overlap. |
| TITLE_BLOCK_NOTICE_OVERFLOW | WARNING | pdf | The project's `notice` text does not fit the title block's notice cell and would be cut. | Shorten the project's `notice` text. |
| TITLE_BLOCK_NO_ROOM | WARNING | pdf | The sheet format's title-block band is under the required 20mm, so it has no room for the standard title-block fields. | Choose or author a sheet format whose title-block band is tall enough. |
| TITLE_BLOCK_TEXT_OVERFLOW | WARNING | pdf | A one-line title-block field (title, number, customer, revision, date, author, page title, scope, or sheet counter) does not fit its cell and would be cut with "…". | Shorten the overflowing text, or rely on the shorter fallback label where one applies. |
| TITLE_BLOCK_UNIT_IDENTITY_MISSING | WARNING | pdf | A unit document's unit has an empty `title` or `number`, so that title-block cell will print empty. | Give the unit release a `title` and/or `number`. |
| TOML_INVALID | ERROR | library load | A part-file is not valid TOML and could not be parsed. | Fix the TOML syntax error the message names. |
| UNCONNECTED_PIN | INFO | kicad | A pin of a board part is in no net in the KiCad netlist. | Usually nothing to fix: wire the pin only if a connection was actually intended. |
| UNIT_BOUNDARY_BYPASSED | ERROR | validators | A conductor or mate crosses out of a unit at a function that is not declared that unit's boundary. | Declare the function as the unit's boundary, or route the connection through an existing boundary function instead. |
| UNIT_CONNECTOR_DANGLING | WARNING | validators | A terminal or connector function belongs directly to a unit, is not its boundary, and connects to nothing. | Wire the function, or remove it if it is not actually needed. |
| UNIT_CYCLE | ERROR | validators | A unit's parent chain loops back on itself. | Break the cycle by correcting the parent authored on one of the looping units. |
| UNKNOWN_SYMBOL_KEY | ERROR | render | A placement's symbol key is not in the installed symbol library. | Fix the symbol key (rule, choice, or part data), or install a library version that has it. |
| UNUSED_CONTRADICTED | WARNING | validators | A boundary declared unused names a function that either is the boundary of no unit, or is in fact connected across a unit it is declared unused on. | Remove the `unused=` if the function is actually wired, or fix which unit/function it names. |
| WIRE_COLOUR_UNKNOWN | ERROR | validators | A wire or cable-product core colour is not a recognized IEC 60757 colour code (or combination). | Correct the colour to a valid base code, a combination of two base codes, a base code with a core number, or the reserved shield code `SH`. |
| WIRE_NOT_ORTHOGONAL | WARNING | render | A drawn route has a segment that is not orthogonal (not purely horizontal or vertical). | Usually a layout-engine artifact rather than an authoring fix. Report it if it recurs. |
| WIRE_OVER_LABEL | WARNING | render | A drawn route runs through a label's (or link marker's) box. | Rearrange the crowded labels/markers (via authored hints) so the route has a clear path. |
| WIRE_THROUGH_SYMBOL | WARNING | render | A drawn route runs through the keep-out box of a symbol it does not end at. | Rearrange the layout (via authored hints) so the route does not need to cross that symbol. |
